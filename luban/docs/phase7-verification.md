## 一、如何复现自动化验证

```bash
cd luban
npm install
npm run typecheck   # tsc --noEmit（0 错误）
npm run build        # 产出 dist/
npm test              # vitest：本阶段未新增用例，全量仍为 129 条
npm run lint           # eslint（0 错误）
```

加载扩展：`chrome://extensions` → 开发者模式 → 重新加载 → 选 `luban/dist`。每一项操作前，在要操作的那个网页上点一次工具栏里的鲁班图标。

## 五、诚实边界

- **本阶段只验收了离线。** 第 1–4 项通过。第 5–32 项（其余错误场景、10 个 Benchmark、10 站点注入）暂不验收，PRD §10.3 五项不判 PASS/FAIL。
- **没有性能数字。** 上下文采集 P50 < 100ms、E2E P95 ≤ 15s 未采样，`docs/mvp-acceptance-report.md` 未写。
- **额度耗尽没有单独文案。** 401 是 Key 无效，403 是 Key 过期或权限不足，429 是调用太频繁。服务端若用别的状态码表示额度用完，会落到「AI 服务返回错误（HTTP n）」。
- **跨域 iframe** 没有「无法完整读取该元素所在区域」这条专用提示。
- **Phase 0 的 10 站 Spike 表仍是空的**，Phase 7 的站点矩阵不能从那份记录继承。
