## 统一检查项

1. 页面首次采集、批次与未覆盖范围；可见广告证据与父子容器范围。
2. 普通聊天/分析不会自动生成；目标确认、生成、运行授权分离。
3. 临时隐藏所选范围后，对原范围做效果检查，不将空白 iframe 或无文本节点直接当作广告。
4. 正文、导航及非目标区域是否保留；页面视觉效果与自动报告是否一致。
5. 动态素材、延迟加载、节点替换或选择器变化是否正确失效；缺少证据时不报告通过。
6. 只有通用机制需要修复时才修改产品代码，站点域名/选择器仅出现在本次任务制品及验收夹具。
