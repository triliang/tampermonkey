# G4 第二轮复核与修复

## 复核项

- 运行时边界：检查页面注册器、网关、UI、领域层及 Harness 运行时；原有站点/广告专项匹配与文案已移除。边界扫描已接入验收脚本。
- 授权边界：下一批绑定会清除旧确认/方案/决定；普通聊天不生成；检查没有所选目标时拒绝，不会把整批结构证据直接当成业务目标。
- 验收边界：保留区域基线在实际运行前刷新；旧效果记录清除；旧检查版本的缓存不展示为新版通过。报告只判断局部计划，明确不判断完整业务目标。
- 定位边界：目标替换不自动重绑定；重复 ID 使用通用唯一选择器生成；父子关系提供给 Agent，不自动扩大操作范围。

## 本轮自行发现并修复

通用采集每批可达 40 个候选，原手动补选也共用 40 个上限，导致满批时无法补选。现补选可裁剪一处未选结构证据，为手动目标腾出位置，保留用户已经选择的引用；在提示中明确裁剪，重新确认范围。已选满 40 项时拒绝扩展，不会悄悄丢弃所选目标。增加 3 项内容层/网关回归用例，受影响 3 个测试文件共 41 项通过。
