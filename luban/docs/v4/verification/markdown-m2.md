# M2：面向用户的回复规则

状态：完成。

Deep Agents 系统提示新增：

- 默认引用“候选 1”“候选 4”及位置、类型、可见特征，避免展示 UUID、RPC、内部状态字段或工具函数名。用户明确询问技术细节时允许解释。
- “我可以用 propose_targets”改为“我可以标出建议处理的区域，供你确认”。
- 窄侧栏优先短段落和编号列表；仅多属性对比才用简短表格，前后留空行，不放长标识符或大段代码。
- 无文本 iframe 是嵌入区域候选，不能直接断言已确认广告；重叠关系依据证据说明不确定性。

预期回复示例：

> 找到 4 个候选区域：
>
> 1. 候选 1：嵌入区域，内部内容未读取。
> 2. 候选 2、3：两个嵌入区域，是否重叠还需定位核对。
> 3. 候选 4：站点标志附近的广告容器。
>
> 这些仍是候选。可以先定位核对，再选择需要处理的区域。

提示词约束不等于确定性输出过滤；后续模型仍可能偏离，需要持续抽验。不通过删除/改写原消息来隐藏历史中的内部标识。
