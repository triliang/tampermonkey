## 本轮通用修复

1. 候选引用：真实模型选择了博客园 label=22 却称“候选1”。系统提示要求严格沿用 targets[].label；界面增加确定性的“当前选择：候选22”摘要。重试真实分析已正确称22。
2. 长页面保留检查：发现范围上限800与目标发现共用，真实页面普遍超过800。独立保留检查上限改为10000，超出仍标记不完整；单次检查缓存 computedStyle，避免重复祖先计算。目标发现仍为800、每批40，没有放开到无限扫描。
3. 无文本证据：纯空格文本 trim 后使用中性 href/src 补充描述，不做广告或网站分类。
4. 新增通用回归：1200节点长页、空白文本链接、非连续候选编号。超过10000节点的截断用例全池运行耗时较长，仅此用例超时改为20秒。

修改文件：src/content/annotations/registry.ts、对应测试、src/sidepanel/v4/HarnessChat.tsx、对应测试、harness/src/runtime.ts。没有加入网站域名、广告关键词或固定站点选择器。站点选择器仅存在当次模型生成的任务草稿及本目录证据。
