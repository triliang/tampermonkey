# M1：Markdown 渲染

状态：完成。

原轻量渲染器只支持段落、列表、标题、引用和代码，没有表格识别，导致管道符和分隔线直接展示。

现已支持表头、分隔行、表体、列对齐、行内粗体/代码/安全链接；支持可选外侧管道符、转义管道符、行内代码中的管道符和缺失单元格。表格局部横向滚动、单元格换行、表头语义和键盘焦点，不撑宽侧栏。代码围栏与普通文本不会误判为表格。

编号列表使用 ol/li value 保留原始编号；“1、4”不变成圆点或错误重编号。

验收：新增 ChatMarkdown.test.tsx 四项行为测试通过，原 ChatArtifact 安全渲染回归通过。HTML 始终作为文本，不使用 dangerouslySetInnerHTML，不加载模型输出图片；危险链接不能执行。总结果见 M3。
