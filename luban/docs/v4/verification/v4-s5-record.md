## 第一轮发现与修复

1. 默认 V4 导致旧 V3 UI 用例落到新界面：增加显式 initialMode，原用例明确验证 V3，新组件另测。
2. 补充候选提交与独立试运行前的 V4 来源、方案、目标校验，未通过时不执行。
3. 扩展 SDK 工具联合类型与 Worker checkpoint 返回类型按实际声明修正，TS 编译通过。
4. 本机协议模型起初复用响应 ID，造成 LangGraph 消息归并异常；修正测试服务为每轮唯一响应 ID，真实 Worker 闭环通过。
5. Bridge 套件需要 Unix socket：沙箱内 EPERM 不记功能失败；在获准的本地测试环境重跑后通过。
