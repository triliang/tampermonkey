## 发现、修复与回归

1. 侧栏 message 含 expectedRevision，而领域严格 Schema 未接收。修复为可选接收且验证版本；新增实际载荷与过期版本测试。
2. 重连后模型配置清空，原入口隐藏/禁用，无法恢复。增加始终可访问的重新启用模型、连接设置入口；兼容序列化错误显示，避免 `[object Object]`。新增组件回归。
3. `withStructuredOutput` 的 SDK 解析器在真实返回形状下抛 TypeError。改为 bindTools 获取原始消息，严格校验唯一指定工具或完整 JSON 正文；拒绝未知/多个工具及非法权限。本机真实 Worker 额外覆盖 tool_calls:null + JSON 正文。
4. 初始候选主要命中广告角标，跨域广告外框漏检。补充已知广告 iframe 外框识别，不读取 iframe 内容；编号标签与边框统一颜色，侧栏显示有界采集覆盖范围。新增注册表回归。
5. 生成候选过度防御，引用 unsafeWindow、修改导航 CSS。保持质量门禁，收紧 hide/dim 的最小 CSS 生成要求与 grants Schema（仅空或 GM_addStyle），不通过扩权放行。
6. 增加模型失败脱敏分类及本机最近失败诊断，仅保存分类、时间、错误类型和去路径调用帧，不存响应、提示词或凭据。

后续实际操作结果将在本记录继续更新；本文件的状态优先于此前未执行的清单说明。
