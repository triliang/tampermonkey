# U1：单一 Chat 与旧会话兼容

状态：设计已落实。

- 原 App 保留品牌、当前网站、消息列表、输入框、我的工具、脚本制品、查看/编辑/运行/保存。
- 移除“V4 对话／脚本工具与历史”双界面切换。页面证据、需求及方案作为原对话内卡片。
- 原 workspace ID、原 IndexedDB 历史与草稿不迁移删除；按 workspace 关联内部 Harness 状态，首次开放时有界导入历史上下文，后续开放不重复导入。
- 原消息附件与代码引用继续从原记录展示；当前草稿/保存版与显式代码引用作为对话数据交给 Agent，不作为生成授权。
- 当前标签页记住原工作区；打开历史和恢复输入只做本地恢复，不调用模型或生成。

新 Agent 消息带稳定 ID 写回原 IndexedDB 消息记录，重复快照不会重复追加；仅更新消息与活动时间，不修改草稿版本或未发送输入。内部检查点仅为同一工作区的运行状态。

验收通过：历史导入/幂等/裁剪、统一时间线与 App 集成测试；真实模型可在原 Chat 解释已有脚本，见 [U3](./unified-chat-u3.md)。
