# U2：原 Chat 接管与原位脚本制品

状态：实施完成，自动验收通过；真实 Chrome 的普通对话与恢复通过。原试运行/保存本轮执行原有回归，未重复远程生成后的完整人工效果确认。

| 项目 | 验收标准 |
|---|---|
| 单一输入 | 原 #intent 输入框完成普通对话；无独立 Agent 输入框或版本切换按钮 |
| 生成边界 | 默认发送只调用 harness.message，未走原 PREPARE_GENERATION 自动生成路径 |
| 上下文延续 | 原消息、附件、引用、未发送输入与已有草稿可恢复；历史不重复展示 |
| 原位候选 | 检查后在原工作区更新草稿；当前消息及输入不清空，运行和保存独立 |
| 防重复覆盖 | 已应用候选标识恢复后仍有效，不允许重复点应用覆盖后续编辑 |
| 作用域 | 轮询、打开结果和提交回调按 workspace/代次检查，防止切换后写回旧状态 |
| 原工具能力 | 原脚本查看、编辑、试运行、效果确认保存、保存版复用和历史保留 |

实现与测试：`App.unified-chat.test.tsx` 使用原 WorkspaceStore 验证旧历史、草稿、输入恢复和候选原位应用；`HarnessChat.test.tsx` 验证单一输入、消息去重、工作区切换及配置等待期间的旧请求隔离；`agent-history.test.ts` 验证持久消息追加不改草稿版本；`harness-history.test.ts` 验证 UTF-8 上下文预算。Bridge 领域测试覆盖历史导入一次及裁剪边界。

复核修复：打开与配置的异步返回均检查工作区/代次，切换后不继续发送旧消息；过期页面提示不遮挡普通对话处理状态；停止按钮统一为“停止处理”。详见 [U3](./unified-chat-u3.md)。
