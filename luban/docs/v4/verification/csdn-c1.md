# C1：定位与优化清单

真实只读 DOM：顶部广告 iframe 位于 `#banner-box` → `.banner-img-active` → `#kp_box_987`；右侧轮播多个 iframe（585/588/589/591/592）均在 `#kp_box_www_swiper` 内，各素材外有动态 `el-carousel__item`。其上级 `#www-home-silde` 同时含社区推荐，不能整体隐藏。

问题与优化：

1. 旧扫描逐 iframe 编号，轮播不同素材混淆为多个广告位；隐藏一个后下一帧仍出现。改按完整广告位容器归一并去重，保留社区推荐。
2. 无文本 iframe 没有语义、位置和数量证据。增加 description、tag、bounds、members、命中理由，让 Chat 能解释轮播与重叠。
3. 唯一选择器只在扫描时验证，动态重排可能偏移。提交/生成时重新验证实际节点；广告位身份不绑定轮播子节点数量。
4. Chat 用户已说明要隐藏仍反复卡在目标确认。提供全选与“确认所选并采用隐藏方案”；生成和运行仍独立授权。
5. 旧执行回执只是脚本执行成功，不能证明广告消失。新增只读可见性/已知广告残留检查，输出 hidden/visible/missing/changed；节点消失不冒充已隐藏。
6. 失败反馈缺少当前证据。检查类消息带入最新检查数据，要求 Chat 据证据解释遗漏并引导重新识别，不直接重复生成。

上述原因针对本次实际 DOM；旧编号不作为新扫描的永久身份。iframe 内部内容未读取。
