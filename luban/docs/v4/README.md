## 体验方式

直接打开 `demo-v4.html`，CSS 与 JS 需保持在同一目录；也可在仓库根目录运行：

```sh
python3 -m http.server 8764 --bind 127.0.0.1 --directory luban/docs/v4
```

浏览器访问 <http://127.0.0.1:8764/demo-v4.html>。

推荐体验顺序：

1. 点击“01 只聊不生成”，观察没有制品产生。
2. 点击“02 广告识别与改造”，观察页面编号与右侧候选清单。
3. 取消勾选 2 号编辑书单，点击“定位”检查对应区域；支持关闭和重新显示标注。
4. 点击“确认所选目标”，选择“隐藏这些区域”或“弱化这些区域”。
5. 点击“确认并生成”；此时页面没有改变。
6. 查看代码，点击“试运行”，在弹窗中独立确认执行。
7. 检查左侧效果，点击“效果符合并保存”；自动运行仍未开启。
8. 点击“模拟页面变化”，观察旧确认失效、旧草稿保留；点击“重新识别”继续。

其他可试路径：

- “手动补选”：确认加入 4 号正文订阅模块，原目标确认失效。
- “切换标注颜色”：只影响标注，不触发脚本生成。
- “只需标注”：任务可以独立完成。
- 勾选“下次生成失败”：失败不创建新草稿。
- 生成期间点击停止按钮：取消本次模拟生成。
- 输入框支持 Enter 发送，Shift+Enter 换行；示例语义包括问答、优化建议、广告标注、排除目标及明确生成请求。

顶部场景切换、故障选项、模拟页面变化和重置属于评审工具，不属于正式产品导航。

## 模拟边界

这是本地产品原型，不调用真实模型、Deep Agents、Bridge、Codex 或外部网页。识别结果固定为示例候选，2 号是用于展示纠错的候选；手动选择只提供一个预置区域。

代码是示例文本，试运行只通过预置 DOM class 改变示例页，不执行生成代码。保存只存在当前 Demo 内存，刷新清空。原型没有实现真实授权、跨进程恢复、模型取消或外部入口兼容，不能作为这些功能已验收的证据。
