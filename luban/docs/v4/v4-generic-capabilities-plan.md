# 通用页面能力重构执行计划

日期：2026-10-18。以 `../../AGENTS.md` 为强制边界。取消网站和广告专项适配，保留 CSDN 作为历史回归案例。

| 阶段 | 内容 | 自动验收标准 | 文档 |
|---|---|---|---|
| G1 规则与设计 | 固化通用边界；页面证据、业务判断、授权、验收分层 | 规则落盘；确定全部特判删除点及验收语义 | verification/generic-g1.md |
| G2 实施 | 通用结构采集与分页、属性和关系；严格失效检查；非目标区域保护；通用 UI/提示词 | 跨布局证据可采集；无网站/广告识别规则；不再放宽容器指纹 | verification/generic-g2.md |
| G3 验收 | 两项 CR 反例、局部计划、弱化、分页及授权回归；构建/测试/打包 | 误伤整页不能通过；内容替换不能沿用确认；未选元素不当作残留目标 | verification/generic-g3.md |
| G4 再复核 | 静态边界检查、检查范围与授权复核、修复遗漏，形成报告 | 再跑受影响检查；列出无法自动判断的语义目标与真实环境状态 | verification/generic-g4.md、v4-generic-capabilities-report.md |

自动效果检查仅回答已确认计划的可观测条件，不能自行判断“所有广告是否全部消失”等语义完整性。需要 Agent 依据重新采集的页面证据和用户验收继续分析。
