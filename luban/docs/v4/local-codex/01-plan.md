架构选择：Codex App Server 作为 LangChain BaseChatModel 的传输后端，通过结构化输出返回文本或工具请求；工具仍由 Deep Agents 和 Bridge 域状态机执行。Codex 本身不接管浏览器、文件、命令、MCP 或其他会话。沿用工作区会话，模型传输使用短生命周期隔离线程。

版本策略：移除单一构建号相等限制，组合检查可识别版本、限制功能标志与实际 App Server 协议。未知/缺失限制能力失败关闭，不能仅凭版本号放行。

真实模型调用允许使用已登录的本地 Codex，仅发送合成测试数据，不读取或输出账号凭据；不执行生成脚本、不保存、不改用户站点。Chrome 已安装扩展端到端效果另行记录，不能冒用既有五站结果。
