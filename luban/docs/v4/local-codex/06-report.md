## 交付结果

V4 Harness 已支持本机 Codex 和原 API 两种模型后端。原聊天新增可用的“执行方”选择；切换沿用当前工作区、历史、输入、草稿及确认状态，没有新建一个产品会话。Codex 使用本机已有登录和默认模型，无需 API Key；推理仍由配置的模型服务提供。

Deep Agents 继续管理工具循环和 checkpoint。Codex 通过 App Server stdio + outputSchema 作为 BaseChatModel 后端，返回文本或工具请求；不直接操作浏览器、文件、命令、MCP 或其他桌面会话。分析、目标确认、生成批准、运行和保存的边界保留，未引入任何网站或特定任务适配。

精确构建号限制已改为版本输出识别、19 项限制标志和所需协议字段检测；本机 0.163.0-alpha.10.2 已真实通过。缺少限制能力或协议不兼容仍拒绝。该探测不修改 Codex 配置、不读取或复制账号凭据。

## 使用方式

本机Bridge已实际运行0.6.7，原鲁班扩展已重新加载修复版本。在原侧栏选择“本地 Codex”继续，无需API Key。当前工作区、历史、草稿保留。会话引用失效会重新解析/恢复；页面授权与生成批准不自动继承。API模式仍可明确切回原设置，不会静默降级。

原生侧栏真实流程与截图见 [完整交付报告](./end-to-end/05-report.md)。

## 本轮真实界面结果与限制

本次已补齐原先缺失的Chrome安装版原生侧栏验收。真实模型提议单个横幅目标，确认并单独批准后生成、检查、试运行成功；目标隐藏，763处非目标区域检查无异常，导航和20篇文章可见。模型正确依据效果证据复核。没有保存脚本或启用自动运行，自建测试页已关闭。
