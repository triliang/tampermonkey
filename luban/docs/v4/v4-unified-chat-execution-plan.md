# 单一 Chat 升级执行计划

用户确认：直接升级原 Chat，保留原会话与脚本能力，移除独立 V4 入口。

| 阶段 | 工作 | 验收标准 | 阶段记录 |
|---|---|---|---|
| U1 交互与兼容设计 | 原 App 为唯一聊天容器；Agent 与同一 workspace 绑定，旧历史只导入上下文一次 | 不创建第二个用户会话入口；旧消息/草稿/引用保留；打开历史不触发模型或生成 | [U1](./verification/unified-chat-u1.md) |
| U2 实施与定向回归 | 接管原输入框；内联需求/目标/方案卡；候选原位应用草稿；独立运行保存 | 一套输入框；普通发送不走旧直接生成；应用前门禁；不重复覆盖草稿；切换工作区无串线 | [U2](./verification/unified-chat-u2.md) |
| U3 整体验收与修复 | 类型/Lint/扩展/Bridge/Harness、真实 Chrome 抽验、报告同步 | 全套检查通过；明确区分自动、真实 UI、尚未执行项；发现问题修复后复验 | [U3](./verification/unified-chat-u3.md) |

内部 Deep Agents 检查点仍是技术运行状态，通过 workspace ID 映射原会话，不作为用户新建会话。历史完整保存在原浏览器库；模型上下文按既有上限裁剪，不以迁移为由删除原记录。旧稿不自动重新生成或执行。

执行结果：U1–U3 已完成；最终 11 项检查及 496 项测试通过。真实 Chrome 与 MiMo 完成已有脚本讨论、消息去重和侧栏重开恢复验收。范围限制见 U3。
