# 连续同类活动合并

日期：2026-10-27。

问题：界面逐条展示工具完成事件；多次检索都映射为“检索页面线索”，造成重复刷屏。原时间为相对本轮开始的累计时间，不是单次工具耗时。

实现：仅合并连续相同类型的可展示事件，显示真实次数和最新事件的相对时间，例如“检索页面线索 · 6次 / 开始后25秒”。检索→读取→再检索保留为三段；不同工具即使通用标签相同也不合并。完整事件数组和链路记录不变，没有减少或伪造实际调用次数。

验收：过程展示文件10项测试通过，含6次检索合为1行、累计次数、最新时间、原日志不变与跨步骤不合并反例。类型/生产构建通过，diff空白检查通过。只修改展示，未重跑模型/Native链路或宣称检索效率提高。版本保持0.4.3，重新加载扩展后生效。
