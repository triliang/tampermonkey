# v4.3 交互演示与检查记录

日期：2026-10-20。依据 [UI/UX 设计](03-ui-ux.md) 制作 [独立 HTML 演示](demo-v4.3.html)，无依赖、无模型请求。可直接用浏览器打开文件；剪贴板能力视浏览器本地文件权限而定。

## 评审路径

1. 点击默认需求示例，授权读取本地示例页。
2. 展开分析过程，进入范围核对，可取消目标、定位及切换隐藏/弱化。
3. 确认范围后，单独授权生成。
4. 查看完整脚本，检查元数据、编辑与版本标记。
5. 单独授权试运行，再单独保存；保存后可导出示例 `.user.js`。
6. 从设置进入服务详情，体验测试、错误、未保存修改与保存反馈。
7. 用底部评审场景切换正常检查、覆盖不足、保留异常或执行前页面变化；可重置演示与切换窄侧栏。

- 授权读取 → 自动分析 → 范围核对 → 独立生成 → 制品 → 独立试运行 → 保存后出现导出入口。

## 模拟边界与待验证

- 模型分析、证据、检查、服务连通性、配置和保存均为模拟；刷新后恢复初始演示状态。
- “试运行”使用固定模拟器修改示例 DOM，**不会求值或执行编辑器中的任意代码**；代码编辑后的基础头检查不代表语法、安全或独立兼容验证。
- 导出生成真实下载文件，但仅匹配 `demo.example`；尚未在 Tampermonkey 中安装验证。
- 未接入生产页面授权、目标身份验证、存储、手动补选、本地服务或外部集成。
- 保存通过正常模拟检查演示；不能据此判断所有生产保存门禁的最终设计。
- 真实页面精准度、预算/无进展循环、全套异常恢复、读屏与完整键盘路径、200% 缩放、低高度和所有目标浏览器仍待验证。

本演示用于评审信息结构、关键授权和状态反馈，不构成生产实现或上线验收结论。
