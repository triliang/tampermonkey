# 结构增强 BM25 与批量读取

日期：2026-10-27。用户授权实现并做对照验证。

## 执行计划

1. 冻结当前观察采集、词法检索为独立基线，固定页面、需求和预算对照。
2. 为观察增加有界祖先、邻近标题和子块摘要；保留真实节点身份、输入值排除、不可见范围与截断说明。
3. 保留 BM25，使用结构上下文辅助排序；重复容器合并仅限返回证据，不自动归并执行目标。
4. 增加最多 8 项的批量读取，逐项重验、逐项报告过期，禁止任一未知引用；贯通 Content、Gateway、Bridge、Harness。
5. 验证跨布局召回、负例、失效和权限、调用预算，分别报告真实浏览器、协议模型与真实模型结果。合成召回不称为语义识别准确率，工具次数不冒充主模型次数。

## 验收与复核

### 实现

- `ObservationBlock.structure` 增加最多四层祖先范围内的命名/标题语境、两个直接相邻块、四个子块摘要。过滤空容器摘要与重复容器正文；每项文字最多 80 字符，结构覆盖截断显式说明。摘要不携带可执行引用。
- BM25 继续检索原名称/文本/属性，增加这些结构词面信息。仅在匿名 div 与直接子块文本/名称相同、子块得分不低时压缩重复容器；保留命名容器与独立同名按钮，不自动选择父范围或写入任务同义词。
- `read_dom_blocks` 最多 8 个不同、已由搜索返回的引用。一个领域调用、一次页面消息，按输入顺序逐项重验，返回成功事实或 `TARGET_STALE`。未知、重复、超量引用直接拒绝；重排、缺项、伪造回包原子拒绝。失败项撤销旧已读事实和报告。
- Content → Gateway → Native/Bridge → Worker/Agent 全链路接入。读取中只有另行验证得到的非空 target 能进入原来的 inspect/review 流程；批量本身不确认、不生成、不执行。
- 主模型上限仍为 8 次，领域工具 24 次、120 秒。核实阶段允许批量读取，报告/最终文本阶段不再开放读取。增加工具说明引导优先批量核实。

### 固定浏览器检索对照

[完整检索数据](evidence/2026-10-27/structured-bm25/retrieval-comparison.json)。15 个合成样例每组 3 次，共 90 条。包括上下文同名按钮、多目标、精确名称、无匹配和中英文无词面对应反例；部分样例仅样式不同或共享结构，不算独立语义样本。

| 指标 | 冻结基线 | 结构增强 |
| --- | ---: | ---: |
| 有金标的 39 次试验平均 Recall@20 | 0.9231 | 0.9231 |
| 所有金标均召回 | 36/39 | 36/39 |
| p50 / p95 本地采集与检索 | 0.9 / 3.6 ms | 1.0 / 3.7 ms |
| 平均完整采集证据大小 | 8,137 字节 | 13,865 字节 |

三个失败均来自同一个“推广”对英文 Sponsored 的无词面匹配反例，结构增强没有解决同义词。候选召回无提升，结构信息收益要看模型能否关联区域；不能将原有高候选召回率当成页面语义准确率。相对排名字段只在有 DOM id 的结果中计算，不能当绝对检索排名。

### 真实模型对照

[9 次运行的原始结果、最终回复与工具序列](evidence/2026-10-27/structured-bm25/model-comparison.json)。同一账户默认 Codex 模型、相同合成页面/需求和预算；三类需求每组各一次。A 冻结基线，B 新采集/检索配旧单项读取 Agent，C 新采集/检索配批量工具和使用指引。

| 合计（每组 3 个任务） | A 旧版 | B 仅结构 | C 结构＋批量 |
| --- | ---: | ---: | ---: |
| 主模型调用 | 13 | 12 | 12 |
| 领域工具调用 | 17 | 12 | 10 |
| 严格完整任务通过 | 2/3 | 2/3 | 2/3 |
| 报告引用集合与金标一致（不等于完成） | 2/3 | 3/3 | 3/3 |
| 证据返回字节合计 | 15,222 | 23,575 | 21,634 |
| 总耗时 | 116.8 秒 | 104.5 秒 | 105.7 秒 |

逐项观察：

- Billing 区域同名 Edit：A 无法建立层级关联，返回 incomplete；B/C 正确引用目标并 answered。模型调用 5 → 4，工具调用 6 → 3。
- 两个登录按钮：三组实际引用均正确。A answered，B/C 因 iframe/Shadow DOM 覆盖限制仍 incomplete，因此 **严格完整任务通过数没有提升**。工具 9 → 7 → 5，模型均 5 次。不能把已找对候选或更保守的报告改写成完整识别通过。
- 无退款入口：三组都没有虚构目标，都报告证据不足；均 3 次模型、2 次工具。

结论：有限样例支持层级关联和工具往返有收益；批量自身没有额外降低主模型调用。总体完整任务通过数相同，证据体积反而增加，未证明整体识别率、token 或费用稳定改善。默认模型版本未固定、没有随机顺序、每任务单次，耗时差异不能归因于算法。金标为自建程序声明，结果由本轮阅读核对，未经过独立人工标注审查。

### 回归与端到端

- 扩展 498、Bridge 113、Harness 41，共 **652 项**自动测试通过；构建、类型、lint、Bridge 打包通过。日志在本轮证据目录。
- [原有检索回归](evidence/2026-10-27/structured-bm25/regression/retrieval-benchmark.json)：40 样例 × 3 次，Recall@20=1；长文档尾部采样、800/240/90KB 上限、节点替换与保护根检查通过。
- [隔离 Native 端到端](evidence/2026-10-27/structured-bm25/native/native-dom.json)：20 项检查通过。真实 Chrome、Content/Gateway/Native/Bridge/Worker，两个观察一次批量读取；另覆盖只读不生成、独立授权、生成/运行/保存、保留正文和导航、导航后引用失效。模型为本地协议夹具，不能冒充真实模型准确性验收。
- 浏览器与模型对照是实际浏览器 DOM 加隔离派发器；生产消息路由由 Native 验收单独证明。未复验原业务页面，未读取真实用户数据。
- 初轮高并发回归有一项既有大页面保留检查超时；独立复验及最终并发 2 的全量通过。预算收尾旧夹具直接注入未注册观察被新校验拒绝，改成先搜索再读取后通过；未放宽生产校验。

### 复核与交付

引用身份、已读事实、观察/目标分离、输出容量、预算和独立授权均保留；新增失败项与非法回包反例。未增加向量库、embedding、HtmlRAG 模型、站点规则或广告识别特判。构建及本机 Bridge 包已更新，未替换日常浏览器注册或声称驻留进程已热更新。

使用新版需重新加载扩展与驻留 Bridge、在目标页重新授权。当前模型结论仅覆盖合成样例；原业务页及完整业务目标仍待实际复验。

### 复现

先构建扩展、Harness，并执行 Bridge 的 `scripts/package-bridge.mjs`。使用 Node 24.14.1，设置 `LUBAN_PLAYWRIGHT_MODULE`、可选 `PLAYWRIGHT_BROWSERS_PATH` 或 `LUBAN_CHROME_EXECUTABLE`；`LUBAN_ACCEPTANCE_OUTPUT` 可指定独立证据目录。

```sh
node luban/scripts/compare-v43-structured-retrieval.mjs
node luban/scripts/compare-v43-structured-retrieval.mjs --live
node luban/scripts/verify-v43-retrieval.mjs
node luban/scripts/verify-v43-native.mjs --entry --dom --batch
```

真实模型对照支持 `LUBAN_COMPARE_MODEL` 显式固定账号可用模型、`LUBAN_COMPARE_REPEATS` 增加重复；默认重复一次，后续重复反转三组顺序。测试不访问真实业务网页。
