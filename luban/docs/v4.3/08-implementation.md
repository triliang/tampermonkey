## S1：Loop 与可信制品底座

新增 `contracts/script-plan.mjs` 及类型声明，扩展与本地服务复用同一确定性规范。

- IR 固定 planHash、hide/dim、完整目标 ID 集合；拒绝扩大/遗漏目标、修改动作与额外字段。
- selector 必须来自宿主；编译器拒绝选择器列表扩展、声明注入、转义绕过和复杂函数选择器等未支持语法。无法验证时拒绝，而不是猜测。
- 只编译固定隐藏/弱化样式，无模型任意代码、外部请求和额外 grant。样式按方案标记，重复调用不重复插入。
- UserScript 头固定顺序、完整字段、单行元数据与 LF 换行；可解析回结构化数据，重复头、权限不符、匹配范围不明均拒绝。

新增 Harness `workflow.ts`：

- L1 外层 LangGraph 调用受限 Deep Agent，之后通过真实页面复核结果决定继续/停止，模型声称成功不能覆盖诊断。
- L2 图验证已批准操作、编译及有限修订；scope/selector/授权改变为硬错误，不交给模型“修好后继续”。
- 实际 hide/dim 固定方案直接构造 IR，无须再调用模型生成任意 JS。可修 IR 的回调边界已做反例测试，生产固定模板路径不额外启用模型修订代理。
- SQLite 中断重建、伪造批准、有限修订、无进展及独立预算均有自动检查。

## S2：生产证据、生成与执行边界接入

- TargetRegistry 新增增量 query、inspect、review；保留原节点身份和单调 label，不因新批次清空选择。cursor 校验节点顺序/身份，拒绝相同节点数下的替换。
- 证据排除输入、编辑内容及其子节点；关系摘要也脱敏、截断。主文档之外的范围明确未覆盖。
- Bridge 新增按 profile/conversation/epoch 隔离的 evidence mailbox，经 Native 轮询、扩展授权校验与 Content Script 返回证据。不依赖侧栏一直打开来处理证据请求。
- 生产提议必须引用通过复核的同一 ID 集合；用户排除项进入任务约束，模型不能无说明地重新选择。
- Worker 的一次自由代码生成改成 LangGraph + 固定 IR 编译，并由 Bridge 对预期编译产物再比对；候选在宿主加入完整脚本头。
- 显式生成批准后自动调度，不再要求“继续/再次生成”；聊天中的自然语言讨论不直接签发生成批准。
- 模型预算在 Bridge 持久记录并校验 epoch；取消、旧回复和未知操作都不能绕过当前状态。
- 试运行和保存保留现有锁、操作身份、凭证与页面绑定；新增头/结构化权限及适用规则一致性验证。保存再核对本次效果与保留报告，不能仅信任 UI。
- 候选到草稿后完整代码仍使用原 draftHash 算法，头也进入 code 字节，因此复制/保存/导出有同版本字节一致性；旧正文及旧 hash 不原地改义。
- Bridge 会话新增 schemaVersion 43，升级清除旧 pending interrupt/批准并保留数据；已中断的生成操作标记未知，显式取消可放弃生成，不影响扩展侧未知运行记录。
- 包装脚本加入共享 contracts 资源，源代码与安装包使用各自受控模块位置。

## S3：交互与设置

- 交流/活动记录/当前决策/制品分开；完整代码不在聊天流铺开。

- 候选首次查看为只读，不改草稿；明确应用候选后才替换草稿。后续制品视图显示独立运行、保存与当前效果报告。
- 历史版本不可显示当前草稿的运行/保存控件；编辑代码不继承旧检查与授权。
- 设置新增概览与服务入口，推理/协议/超时渐进展开；保存和测试分开。表单修订隔离过期响应，服务切换也隔离凭据读取的晚到结果。
- 保留既有工作区、输入、滚动和焦点恢复能力；本次未重写完整视图持久化系统。

## S4：验收与设计差异

详细结果见 [验收记录](09-acceptance.md)。本次选择以下边界明确的实现，不声称原技术文档所有扩展构想均已落地：

1. **执行授权由宿主负责**：生产流程在 Bridge/扩展持久状态中等待用户批准，Worker 只处理已批准生成操作；图中 interrupt 恢复能力已验证，但没有把运行/保存等待重复搬入第二套图状态。
2. **离线验证在测试层**：已在 jsdom 和真实浏览器合成布局验证可信编译产物；没有新增生产隔离夹具执行服务，也不会执行模型/用户任意代码做自动试错。
3. **L3 为宿主效果检查与显式修复入口**：试运行后检查结果进入制品；重新分析可使用绑定的效果报告，修复重新核对和授权。未新增自动连续运行修复链。
4. **增量兼容迁移**：复用既有存储与哈希覆盖完整代码，不引入第二套制品库和分布式事务。旧脚本不会被静默批量改写。
5. **评估不夸大**：真实 Codex 仅完成三份合成任务探针，不构成四组对照、整体准确率或真实站点验收。

这些差异不扩大产品权限。生产隔离验证服务、完整图级全生命周期恢复及大规模准确性对照仍需后续实施/验收；不是本次已交付能力。
