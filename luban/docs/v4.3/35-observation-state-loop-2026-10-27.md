# 报告驱动只读 Loop

日期：2026-10-27。用户确认按 [Loop 审计建议](34-loop-audit-2026-10-27.md)实施。产品阶段 V4.3，扩展仍为 0.4.3。

## 计划与边界

- 报告无效：保留证据，给字段级错误并允许一次定向修正；报告有效：系统直接交付，不额外调用模型改写。
- 明确已知引用的可读缺口：同一任务最多一次定向补证，随后重新校验报告。不可访问范围与歧义仍诚实结束或澄清。
- 用户续查：保留先前任务事实与报告，先重新验证相同文档下的已发出引用，再供当前报告使用。旧事实不能直接继承为当前已核实证据。
- 8 次模型、24 次工具、120 秒、真实节点身份、已读引用与独立生成/运行/保存授权保持。新增校验节点需要图步数容量 64，不改变模型次数上限。

## 最终流程

1. 按需检索并批量读取相关线索；保留原有预算保护：后期只核实已有引用，接近预算时只允许提交报告。
2. 原生报告先校验结构，再由宿主校验实际已读引用。六条理由超过上限等错误会返回字段级反馈，切换为只修正报告；不重新广搜。一次修正仍失败则诚实结束。
3. 有效报告由固定 Markdown 模板展示“本轮判断、尚待核实、下一步”，立即结束模型调用。文本中的伪工具 XML 不会被当作工具执行。
4. incomplete 报告可携带最多 8 个已发出引用作为 nextReadIds。宿主在剩余预算内批量补读一次，再要求只修订报告；第二轮仍有缺口则结束，不循环补读。
5. 技术报告失败显示“重新提交报告”，不会要求用户说明识别范围。用户点按钮后先重新验证保留引用，当前报告不能直接复用旧事实。真实业务歧义仍保留澄清入口。
6. 页面重新绑定会清空旧文档引用。只读/修改的模型会话隔离，补证在同一检查点和预算内进行，不重复回放整段历史。

新增 report.rejected 链路事件，仅记录错误类型、字段名和尝试次数；不保存原始错误参数。自动补读及报告提交继续记录实际工具事件。

## 验收结果

- 扩展：537 项测试通过，正式构建通过，dist manifest 版本 0.4.3。
- Harness：58 项测试通过，包含结构错误修正、立即交付、两次失败结束、文本伪工具纠正、一次补读上限、同一检查点预算继承和页面特殊文本转义。
- Bridge：116 项测试通过，包含未重验旧引用不得用于当前报告、未知补读引用拒绝、错误元数据限制。
- Bridge 发布包已重建。检查日常会话、任务及租约空闲后温和重启日常 Bridge，未清除会话或配对。见 [部署记录](evidence/2026-10-27/state-loop/deployment.json)。扩展前端需在 Chrome 扩展管理中重新加载。

### 隔离 Chrome + Native Messaging + 实际 Harness Worker

模型使用本地确定性协议夹具，页面为通用合成布局；这些证明运行链路，不证明真实供应商模型或 CSDN 业务识别准确率。

| 场景 | 验证结果 | 证据 |
|---|---|---|
| 超过 60 秒进入报告阶段，首次报告理由超上限 | 4 次模型调用完成有效部分报告；无额外最终改写，无广搜恢复 | [10 项检查](evidence/2026-10-27/state-loop/repair/native-budget.json) |
| 报告明确一个已知可读缺口 | 4 次模型调用；两次报告之间只增加一次批量补读 | [6 项检查](evidence/2026-10-27/state-loop/targeted/native-targeted-gap.json) |
| 连续两次输出伪工具文本，随后用户重新提交 | 原轮结束为技术报告错误；重验 2 条保留证据，无新广搜；未发送输入仍保留 | [15 项检查](evidence/2026-10-27/state-loop/markup/native-report-markup.json) |
| 修改任务兼容性 | 范围确认、独立生成授权、试运行、保存及非目标保留检查通过 | [30 项检查](evidence/2026-10-27/state-loop/compatibility/native-dom.json) |

原真实异常轮消耗 6 次模型调用但没有有效报告；本次在不同的可控夹具上验证同类错误可修复。不能将两个不同页面/模型的调用数作为识别准确率或性能提升百分比。

## 复核与剩余限制

- 未新增站点或广告专属运行规则；普通聊天不自动读页面，分析不自动生成或执行。
- 有效报告只代表已读证据满足结构与引用规则，语义正确性仍依赖模型和页面证据。
- 下一步需要用户在重新加载扩展、重新授权目标页面后复测原真实需求，检查是否完成业务识别及调用总数；本轮未使用真实页面或供应商模型替用户作准确率验收。
