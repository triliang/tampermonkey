## 每个场景都检查的阶段

| 阶段 | 通过依据 | 不能当作通过 |
| --- | --- | --- |
| 需求理解 | 原话和补充正确合并，参数与保留要求完整，只追问真实缺口 | 命中动作关键词、套用固定动作菜单 |
| 页面证据与范围 | 节点身份、唯一性、目标与保留范围、输出锚点、覆盖缺口可核对 | 搜索候选、广告关闭标记或相似文字直接当完整业务范围 |
| 生成 | 真实生成调用及完整程序候选，绑定需求/范围/批准/基线 | 口头“已生成”、预制固定 CSS、仅契约接受代码字符串 |
| 通用审查 | 语法、能力、范围影响、参数处理、资源限制检查通过 | 字符串与旧编译器一致、模型自评安全 |
| 独立运行 | 当前版本明确授权，执行前重验身份，真实运行记录 | 生成授权、截图预览或模型工具调用文本 |
| 效果与保留 | 指定目标结果正确，非目标/用户输入/交互/请求符合要求 | 节点不见了、执行没有报错 |
| 保存/导出 | 当前有效版本和效果证据匹配，独立批准，导出权限语义清楚 | 自动保存、旧授权复用、把导出脚本当受控执行器 |

## 分簇验证，减少重复等待

| 场景簇 | 对应用例 | 主要验收点 |
| --- | --- | --- |
| 可见性与节点生命周期 | C01–C07、C21、C25、C26 | 隐藏与删除结果不同；范围不扩大；保留与重复运行 |
| 文本、属性与样式 | C08–C10、C14–C16 | 正确字段变化；链接/图标/事件和输入值保留；参数作为数据 |
| 创建与交互 | C11–C13、C22 | 输出锚点正确；插入顺序；只有授权事件改变输入，不提交或触网 |
| 计数与组合 | C17–C20、C23、C24 | 单位/去重/零值/覆盖；顺序和多目标效果；保留条件 |
| 缺项与只读 | I01–I32、N01–N08 | 缺什么问什么；不因动作词启动错误链路；不生成或执行 |
| 多轮与授权 | T01–T16、A01–A08 | 改写、取消、暂不可用、迟到返回；批准绑定和旧草稿保护 |
| 恢复、动态、交互与布局 | R01–R12、D01–D10 | 超时、节点替换、动态加载、手动点选、隔离、键盘与缩放 |

每簇先在固定夹具验证确定性行为，再用少量真实页面确认识别/模型生成/执行链路。固定夹具至少有平级模块、嵌套保留内容、分栏布局、动态重复/同名节点。夹具可包含业务文案；生产实现不能硬编码站点或广告语义。未命中的特殊语义仍须逐项保留缺口。

自动回归、真实模型语义、浏览器端到端、导出兼容分别记录耗时和结论，不能互换。没有新增代码影响的通过簇不重复全跑；同类模型失败达到上限后聚合修复原因，不逐句消耗完整预算。
