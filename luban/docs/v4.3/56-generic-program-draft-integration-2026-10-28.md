# V4.3 通用程序候选链路接入

日期：2026-10-28。承接 [54 号架构](54-generic-script-architecture-2026-10-28.md)、[55 号清单](55-generic-capability-acceptance-2026-10-28.md)。

## 本轮交付与边界

源码已接入通用程序候选链路，不再仅停留于契约。计划可选择 `program` 通用模式；Worker 根据已记录需求、参数、保留要求、确认范围、证据与旧草稿，实际调用已配置模型接口生成完整源码。`program` 是生成模式，不是业务动作白名单；代码可以表达不同任务及组合。

**新链路仅生成审阅候选。没有接入受控执行、通用效果判定、应用到可运行草稿、运行、保存或导出准出。** 通用候选采用独立的 reviewOnly 状态，旧版客户端所需的 candidate 条件不成立；后续聊天也不会把它升级成可运行状态。服务端和界面均有阻断；绑定校验通过不能替代代码、范围或效果检查。现有 hide/dim 保留兼容快路径。

本轮完成源码、构建和本地真实 Worker/模型协议集成测试；没有打包替换正在运行的 Bridge，也没有重载用户扩展进行线上实机验收。不能声称已配置的线上模型已验证所有 19 个场景。自动生成意图、范围识别、输出锚点与保留范围结构化、完整多轮解析尚未全部闭环。

## 代码变化

| 层 | 变化 |
| --- | --- |
| 需求/计划 | 计划允许 program；保留原始完整请求作为通用目标。需求目标或缺项变化，即使保留条件不变，也撤销旧范围/计划/生成批准 |
| 分流 | 已有目标上下文的明确通用改造请求可进入修改分析；未识别对象的新请求仍优先补全需求，未完成所有自然语言的一次自动续接；能力询问、解释、否定和只读路径优先保留。只是语言分流提示，不作为可支持动作的产品枚举 |
| Worker | 新增 `program-generation.ts`：生成时实际调用模型；正文参数作为数据传递；不调用页面工具或执行源码 |
| 修复循环 | 最多两次模型调用，格式问题最多修正一次；越权、取消或授权失效不作为可继续修复的理由 |
| 宿主 | 生成前验证信封，前后重验实际页面与任务；校验候选证据、权限、批准及版本；保存候选关联及待审查状态 |
| 兼容 | 服务状态新增 genericProgramDraft 能力标识；旧 Bridge 不接收新模式生成，提示更新，不静默降级成隐藏；动作选择反馈改为通用候选流程，不再把删除等描述为产品不支持 |
| UI/执行入口 | 展示“仅供审阅”；禁用应用；阻止通过提交、运行、保存及旧可见性效果检查绕开通用准入 |

新的程序信封在 claim 之前完成结构校验，避免无效输入先占用生成状态。模型预算在宿主持久化，通用生成最多两次，受总截止时间和取消限制。异步模型响应返回时再次校验有效性，不能仅凭调用前的批准写入候选。

## 已验证的路径

本地测试启动真实 Worker，使用真实模型 SDK 访问临时本地协议服务。协议服务提供受控的结构化模型输出；它不是线上模型语义测试，也没有执行生成的 DOM 代码。

测试路径：已授权页面和目标 → 选中并确认范围 → program 计划及保留条件 → 独立生成批准 → 真实模型请求 → 通用源码候选 → 宿主版本/证据校验 → 待审阅制品。

返回的源码包含文字替换逻辑，宿主接受为程序候选，而不是要求与固定 CSS 编译器逐字一致。测试检查完整需求、保留条件和原草稿实际进入模型请求、没有页面工具暴露、模型调用计数为 1、候选带真实任务关联且仍需审查/运行授权。第二次生成返回未知证据，最多两次后失败，原候选保留。

其它反例包括：格式无效的一次修正、持续无效停止、越权能力硬停止、模型自报通过被拒绝、返回时页面/批准已撤销不提交、取消后不调用模型、旧 Bridge 拒绝新协议、通用候选不能应用到草稿或使用旧效果检查。

历史有一条测试把“仅修改需求目标、约束不变”视为可保留批准。本轮修正为：只有同一目标且归一化约束不变才能保留确认；新加独立反例验证目标单独变化也撤销批准，没有放宽批准门槛。

最终回归：Bridge 141/141、Harness 73/73、扩展/界面 705/705，构建通过。通用生成器反例 6 项包含在 Harness 总数中，真实 Worker/本地模型协议集成包含在 Bridge 总数中，不重复累加。

扩展全套曾有一次密集页面采样测试超过原有 5 秒上限：[该次失败日志](evidence/2026-10-28/generic-architecture/program-ui-full-loaded-attempt.log)已保留。随后单独重跑全套 705 项通过，没有修改超时、断言或被测采样代码；单次重跑不能证明所有负载下均无时序波动。最终提示文案与通用候选接线亦有[服务/协议复核](evidence/2026-10-28/generic-architecture/program-service-final.log)。

## 当前进度与下一步

- M0/G01：契约已用于候选入口。
- M1：通用模式、目标及批准失效有源码和回归；完整自然语言/多轮与一轮生成策略仍待完善。
- M2/G03：实际模型接口与候选入库源码接通，本地协议集成通过；真实线上模型、19 项场景及浏览器可审阅流程待验。
- M3/G04–G06：受控运行时、通用 DOM 代理、保留范围的祖先/后代影响检查、隔离资源限制及效果核验仍未实现；不得解禁应用或执行。
- M4/G08：保存、导出和端到端迁移待上述门槛通过。

19 项仍记“通用生成链路缺口”，本轮不改为实机通过；原 112 项实机通过数不变。旧快检中的固定编译器拒绝只代表兼容边界，不再解释为产品通用能力不可支持。
