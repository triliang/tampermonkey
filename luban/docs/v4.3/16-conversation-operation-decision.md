# 确认范围后通过会话提出操作方案

## 当前逻辑核对

原界面在确认目标后提供“隐藏这些区域 / 弱化这些区域”，点击后通过 `decide(action: plan)` 直接创建方案，绕过模型的会话判断。普通聊天已有 `propose_plan` 工具能力，因此固定操作按钮并非必需。

## 本次调整

- 确认范围只确认作用对象，不默认选择操作，不生成脚本。
- 移除隐藏、弱化两个固定按钮，保留“修改范围”。提示用户在对话中说明希望如何处理。
- 用户通过对话表达意图，模型结合需求、保留要求及确认范围提出方案；存在歧义应继续澄清。
- 模型提出方案后仍显示方案摘要和明确的“授权生成”；运行、保存继续分别确认。模型决策不替代用户授权。

## 能力边界

本次调整交互入口，没有扩展脚本操作类型。底层 `propose_plan`、PlanIR 和编译器目前仍仅支持 `hide / dim`。点击、填写、登录等操作不能因为移除按钮而宣称已支持；扩展此类操作需另行设计动作协议、权限、验证及授权范围。原有 `decide(plan)` 兼容接口暂留，本界面不再调用。

## 验收

- HarnessChat 17 项测试通过，包括新增的“确认范围后无固定操作入口、无自动生成”回归。
- 人工复验：确认范围 → 输入自然语言处理诉求 → 核对模型方案 → 授权生成 → 分别确认运行/保存。歧义诉求和超出能力的操作应明确说明，不得静默转换为隐藏或弱化。
- 本次尚未完成安装后真实浏览器与真实模型的上述完整会话复验；前端构建不等于该链路验收通过。

## 移除单独读取入口

按用户要求移除聊天底部“需要分析真实页面时，先授权读取”提示及“授权读取并分析当前页”按钮。没有以移除按钮为由添加隐式读取或自动分析。已有绑定会话可继续使用；尚未绑定的新会话，后续仍需补齐从工具栏打开侧栏到会话绑定的统一入口，不能宣称仅删除按钮就已完成该链路。18 项组件测试、类型检查及构建通过。

## 空白首页布局修正

清除侧栏独立文档的默认 body 外边距，约束根容器高度，避免满视口聊天区再加外边距导致外层溢出；聊天区仅在内容溢出时滚动。未绑定且无活动时不渲染空决策区，移除遗留分割线和占位间距；聊天区与输入区统一白色背景，取消输入区顶部边框。18 项组件测试、类型检查及构建通过。

## 首页改为页面资源列表

移除欢迎图标、标题、说明及三个预设建议按钮，空会话展示当前页面资源概览。通过限定到侧栏所属标签页的只读请求采集主文档：图片、链接、表单、嵌入页面、脚本、样式表；每类显示节点数量，展开最多展示 6 项。列表是采集时的快照，不表示去重网络请求数量或自动跟踪 DOM 变化。

不读取表单值或内联脚本/样式内容；资源地址只展示 HTTP(S) 的 origin 和 pathname，去除账号密码、查询参数和片段。界面明确不覆盖 iframe 内部、Shadow DOM、CSS 背景图及完整网络请求。仅本地展示，不调用模型、不授予生成或执行权限，也不替代 Harness 会话绑定。

20 项相关测试、类型检查和构建通过；新增回归覆盖分类数量、样本上限及敏感字段排除。安装后的实际侧栏视觉和页面切换复验尚未完成。

## 资源列表语义纠正：对齐 DevTools Sources

用户明确“类似 DevTools 里的资源”后，以本节替代上节的 DOM 分类统计设计。首页改为域名 → 目录 → 文件树，显示 HTML、JS、CSS、图片、字体、API 等类型标签，支持搜索文件路径和手动刷新。数据来自主文档文件引用和 Resource Timing 已记录条目，不再把普通链接、表单作为资源项；最多返回 500 个脱敏路径，每类引用和性能条目各最多检查 2000 条，超限提示截断。同 origin+pathname 合并，查询参数版本不区分。

这是资源索引，不是完整 DevTools 实现：不读取响应正文、源码或请求头，不主动请求文件，不含嵌入文档内部、完整网络历史、source map 虚拟源文件或所有 Shadow DOM 资源。Resource Timing 若已清空或缓冲区溢出，索引可能不完整。刷新只更新本地列表，不调用模型，不生成或执行页面脚本任务。

3 项专项回归通过，覆盖域名目录树、刷新、性能资源补充、脱敏与路径去重。实际安装后视觉复验未完成。

## 最终展示调整：按类型直接列出文件

按用户最新要求，取消域名和目录树，改为 HTML 文档、JavaScript、CSS 样式、图片、字体、接口请求、其他资源分组，直接展示每组文件名和脱敏地址，无需展开目录。仅展示有资源的分组，保留数量、路径搜索和刷新。采集边界及脱敏规则保持不变。3 项专项测试及类型检查、构建通过；真实侧栏视觉尚未复验。
