## 1. 判定方式

- **通过**：步骤实际执行、断言满足并保存证据。有限检查只能标该子项通过。
- **失败**：实际行为不满足标准，保留失败原因；修复后记录复验。
- **阻塞**：有明确环境或实现前置条件缺失，不计通过。
- **待执行**：已明确步骤但尚未运行。

本轮使用临时浏览器/profile/合成数据。Native 专用注册在测试浏览器临时 user-data-dir 内创建并在结束时删除，拒绝覆盖已有注册。测试协议模型不用于模型准确率证明。发布仍要求真实模型代表性任务与人工体验验收。

### 3.2 R05：Tampermonkey

只复制本机已安装的 Tampermonkey **5.5.1** 程序，不复制其Local Extension Settings、用户脚本或Cookie。保留其manifest key，临时profile安装并开启允许用户脚本。程序文件hash（不含_metadata）及输入脚本SHA-256见[报告](evidence/tampermonkey-browser.json)。此为现有安装版本，不声明是最新版本或重新执行商店签名校验。

1. 以Native链路实际保存的完整脚本原文作为本地安装URL响应。
2. 通过Tampermonkey正常Utilities→URL→Install界面安装；不调用内部写库接口。
3. `127.0.0.1`匹配页目标自动隐藏、正文保留；`localhost`非匹配页不执行。
4. 单独安装三份合成权限夹具，分别标注document-start/end/idle，验证GM_addStyle、GM_getValue、GM_setValue、GM_deleteValue、GM_info对象、unsafeWindow页面可达。
5. 实际readyState依次为loading、interactive、complete；end/idle仅证明本轮在DOM可用后运行，不保证任意调度下的精确先后。

7项断言通过（后3项每项包含六种能力）。只覆盖本机版本/浏览器；旧函数式GM_info、其他管理器、其他浏览器不纳入兼容承诺。[安装截图](evidence/tm-install.png)、[匹配页截图](evidence/tm-match.png)。
