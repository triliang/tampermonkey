## 1. 实施结果

### 会话主流程

- 修复页面消息分流时丢失用户原始文本：消息现在随 analyze 进入 Bridge，按 requestKey 去重持久化，并优先使用本次输入，避免沿用旧 goal。
- 只读模式在 Worker 限制可见工具，并在宿主拒绝目标提议、方案和生成请求。只读不再被修改任务的 inspect/review/范围确认流程拖住。
- 新增结构化 `report_observation`：结论、已实际读取的证据引用、依据、歧义和缺口。不能用伪造引用报告 answered；空检索明确进入 incomplete。
- 目标、操作和约束的已有失效规则保留；当前 UI 的自然语言方案经实际输入框发送，生成、应用、运行和保存分别验证。

### 宿主预算与停止

- Bridge 为全部模型领域工具计数，Worker 的本地预算继续作为第二道保护；不以重建 Worker 绕过同一 epoch 的宿主账本。
- query/inspect/DOM/资源取证的内容重复可以在 review 前停止；参数指纹、排序、证据版本自增和词法分数均不作为新知识。
- 模型次数、工具次数、总时限、模型请求超时、证据超时、无进展分别保留原因。停止消息不再统一误导用户检查模型配置。
- 分析的调用信号受宿主剩余总时限约束。未提高 8 次模型、24 次工具、120 秒的默认上限。

### DOM 观察与词法检索

- 观察块与可执行 TargetRef 分开。表单、输入标签、导航、正文、按钮、图标和图片可被观察；输入值、密码值、编辑区内容不采集。
- 名称来自 DOM 标签、aria、alt、title、placeholder 等，并注明来源；不是完整浏览器 AX 名称算法。
- Content Script 保留真实节点引用、有界结构块和变更失效；Bridge 执行中文字符/二元组与英文词法 BM25 检索、名称加权和排序。未新增数据库或浏览器会话。
- 单次检查最多 800 个匹配节点、240 个块和约 90 KB 块数据；返回最多 20 个词法结果。截断、频繁变化及 iframe/Shadow DOM 不可见范围明确报告。
- `read_dom_block` 重新核对节点身份和完整脱敏描述，仅在原有安全范围及唯一性校验通过时另行注册目标。观察 ID、检索分数都不能直接用于修改。
- MutationObserver 有界处理变更；繁忙页面保守失效并标记不稳定。下一次检索按需重建有界快照，不承诺持续维护全页索引。

### 资源补证

- 新增资源检索与有界片段工具，资源 ID 内部绑定节点、原始资源身份和内容版本；展示路径仍去掉查询参数。
- 当前明确选择已有可读 CSSOM 作为正文运输方式：最多检查 500 条规则/64,000 字符，每次读取最多 4,000 字符，不重新下载文件或重放接口。
- CSSOM 变更、资源查询版本变化及节点替换使旧引用失效；版本校验同时比较真实对象和原始有界内容，不仅依赖短 hash。
- JavaScript、不可访问跨源 CSS 等返回正文不可用。没有实现缓存 JS 响应抓取、source map 或跨源下载器；这属于明确能力边界，不能标为完整资源 RAG。
- CSS 中存在某选择器不证明当前有对应 DOM 节点，资源引用不注册为执行目标。

### Langfuse

- 日常 Bridge 支持读取其私有目录的 `observability.env`，逐任务加载；拒绝符号链接、非本人文件、过宽权限、未知配置项和过大文件。不需要为了配置切换强杀任务。
- 已在日常目录安装本地 Langfuse 配置；保留既有 Native 注册和允许来源。包已更新，未重写注册或用户数据。
- 真实 Native/Worker 的普通对话、页面补证及生成追踪已通过本地 Langfuse API 回读。仍仅导出元数据，未启用输入输出正文追踪。
- 追踪记录关联 runEpoch/生成 operation；宿主持久记录每轮 traceId 和 completed/failed/cancelled/superseded。强杀缺少末尾 span 时，宿主终态仍独立保留。
- 导出成功、失败、未知与业务结果分别记录；追踪失败不改变授权或任务结果。没有声明扩展内部所有阶段已有完整分布式 span。
