# V4.1 整体复核与优化一轮

## 发现与优化

1. 初版评分把选择器转换为节点集合，重复引用会被集合合并而漏检。增加 duplicate-target 拒绝与反例测试。
2. 统计字段需严格数值类型，不能将字符串或额外字段当正确结果；新增数字字符串与畸形输出反例。
3. 原 V4 门禁默认覆盖历史输出。增加 --output，将本轮证据隔离到 4.1；本轮首次沙箱失败证据另存 baseline-sandbox，历史文件恢复原内容。
4. 模型运行记录补充题集、评估器、运行器与夹具哈希。报告分别统计错误和未执行；延时只对有效响应统计，不把瞬时断连当速度优势。
5. 首次 Bridge socket EPERM 与 Codex AGENT_DISCONNECTED 在受限环境出现；允许本地 IPC 后门禁通过、Codex 开始返回真实答案。保留首次失败，不能事后改为通过。

## 复核结论

本地十九项场景测试通过；既有十项集成门禁通过。测试明确覆盖 DOM 与结构，不能据此证明视觉、Native 常驻版本、多轮模型工作流或全站语义完整性。站点/广告语义仅位于夹具和评估材料。第三方已按用户后续授权成功复用；以最新对比报告为准。

## 保留缺口

模型单轮 JSON 输出受约束，不代表自主工具选择能力。页面注入题是固定样本，不代表注入防御安全证明。金标目前只有四题，需继续扩展长表分页、多单位、异步与 Shadow DOM 的语义样本。跨站“完美识别全部广告”不是本轮承诺。

启动时固定源码哈希，避免运行期间文件改变导致元数据对应错误版本。首轮成功批次只作为中间结果，最终结论以优化后复验批次为准。
