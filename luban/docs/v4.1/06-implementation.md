## S3 模型验证

新增 evaluate-v41.mjs：四题、每题三次、相同系统指令与 HTML；DOM 节点集合对齐目标，统计逐字段校验，不执行模型代码。独立环境变量配置第三方，不自动读取账号密钥。Codex 复用已有限制 Host 工具的 AgentProcess。错误、未执行、语义失败、通过分别记录，缺少任一后端不输出优劣结论。

## S4 自动化

`npm --prefix luban run verify:v41`：本地场景、通用边界与运行器语法，落盘日志与文件哈希。`node luban/scripts/verify-v4.mjs --output docs/v4.1/integration`：原有十项门禁，扩展构建、检查与三个子项目回归；新增 output 参数隔离版本证据。模型单独执行 `npm --prefix luban run eval:v41 -- --live`；缺配置时退出码 2，不能作为通过。
