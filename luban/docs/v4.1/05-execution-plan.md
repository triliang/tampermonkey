# V4.1 分阶段执行与验收计划

| 阶段 | 工作 | 准出与沉淀 |
|---|---|---|
| S0 | 读历史与代码，固定范围和红线 | 01-scope、03-redlines；禁止特判 |
| S1 | PRD 与技术方案、架构图 | 02-prd（用户已确认通用模板）、04-technical-design |
| S2 | 离线 HTML、场景金标、生产代码本地回归 | fixtures、测试、06-implementation |

先完成 S0，再 S1，再实现；用户已确认独立项目模板，正式PRD已补齐。此前模板确认期间仅准备夹具与可行性验证，未改变产品行为。失败自行修复；真实模型失败不伪造通过。每次运行生成新证据，历史报告不作为本轮通过依据。
