# 左侧网页代码浮层验收

日期：2026-10-15。正式代码默认在当前网页内容区展示宽版代码浮层，右侧聊天保持可用；受限页面、未授权网页或注入失败时回退到侧栏。真实 Chrome 视觉与交互待人工验收。

## 1. 环境与打开位置

1. 在 Chrome 扩展页重新加载最新 `luban/dist`。
2. **刷新目标网页**，确保旧内容脚本被替换，重新打开鲁班侧栏。
3. 生成或打开已有工具，点击制品名称。

- [ ] 代码浮层出现在左侧网页区域，占用宽版空间；右侧聊天输入仍可使用。
- [ ] 浮层中有行号、高亮、复制、当前/保存版/上一版选择、编辑与选行操作。
- [ ] 关闭按钮/Esc 退出后原网页恢复，布局、业务样式和脚本未被代码预览修改。

## 2. 选行回到聊天

1. 在右侧输入一段下一轮要求，但先不发送。
2. 在左侧选择单行或 Shift 连选，点击「添加到聊天」。
3. 核对右侧引用、行号、版本与快照。
4. 发送继续修改。

- [ ] 添加后关闭左侧浮层，焦点回到右侧输入，原文字保留。
- [ ] 不自动发请求、运行或保存；发送后引用进入本轮实际上下文和历史。
- [ ] 引用单独添加不使有效试运行凭证失效，已有失效凭证也不会复活。
- [ ] 历史版本引用仍保留来源，并按原规则在过期时要求重新选择当前版本。

## 3. 编辑与保护

1. 在左侧点击「编辑代码」，修改内容，暂不保留。
2. 尝试关闭浮层，以及在右侧点击运行/发送。
3. 选择「保留为未验证草稿」，检查侧栏状态。

- [ ] 未保留编辑须先保留或放弃，不能因右侧生成/运行而静默丢失。
- [ ] 保留后仅更新原工作区草稿；原保存版不变，旧检查/保存资格失效，须重新试运行。
- [ ] 左侧保留编辑时右侧已输入的下一轮文字不丢失。
- [ ] 如代码已在别处更新，旧浮层不能覆盖新稿，应提示关闭重开。
- [ ] 编辑后移除旧代码引用或从当前版本重新选行，过时行号不用于新版修改。

## 4. 更多操作与回退

1. 展开左侧「更多操作与诊断」，点击「在侧栏打开更多操作」。
2. 在侧栏操作名称、权限、版本、导出和自动运行等已有功能。
3. 在不匹配/受限网页或未授权普通网页上打开代码。

- [ ] 左侧关闭后侧栏打开原有操作浮层；权限、恢复、导出等仍走原服务。
- [ ] 无法显示网页浮层时有回退说明，并可在侧栏查看/编辑/引用代码。
- [ ] 左侧工具名作为来源显示，改名在侧栏操作中进行。

## 5. 生命周期与隔离

1. 保持左侧预览打开，实际停止并唤醒扩展 SW，再选行或编辑。
2. 刷新目标网页、切换标签页/工具后再操作旧浮层。

- [ ] 正常 SW 重启可恢复会话，工作区/标签页/document 绑定仍有效。
- [ ] 导航后的旧文档、其他标签页或子 frame 不能回传旧操作。
- [ ] 切换工具/开始新一轮生成或运行前关闭旧浮层；有未保留编辑时要求处理。
- [ ] 会话超过 30 分钟时重新打开；不会恢复旧凭证或覆盖新代码。

## 验证边界

自动检查覆盖真实仓储/版本检查、会话恢复、消息来源隔离、选行/编辑 DOM 交互，以及网页浮层引用回传时保留聊天输入。使用 jsdom 和 Chrome transport 替身，不替代真实浏览器布局、焦点、剪贴板、权限与 SW 强制停止验收。

网页浮层使用内容脚本 ISOLATED 环境、closed Shadow Root 和原生 dialog，独立样式、不执行所展示的代码；不引入额外站点权限。强制关闭侧栏或导航前，尚未保留的编辑/正在输入的文字不保证恢复，请先保留。会话身份元数据持久化在现有 IDB meta，代码仍从原工作区读取，不另存完整副本。
