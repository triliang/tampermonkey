## 交互调整

固定头部和底部 composer，消息为主滚动区；脚本为输入上方单条制品栏，代码通过浮层高亮/编辑。分析和设置在顶部，点选和发送在输入区，运行和效果保存跟随制品状态。澄清以聊天问题与选项完成，简单场景不逐轮弹预览或策略表。

生成过程在同一助手消息内更新，处理摘要可折叠；支持安全 Markdown，原始 HTML 与危险链接不会执行。原型摘要为预设处理步骤，不是模型内部逐字推理。

## 自动检查结果

使用 jsdom 执行真实 Demo 脚本，生成延时缩短用于检查事件顺序：

- 脚本语法检查通过，交互过程未捕获 JavaScript 错误。
- 广告单元素 → 部分生效 → 快捷反馈填入 → 模块确认 → 完整隐藏 → 保存通过。
- 初始无制品栏、制品打开、代码高亮、编辑后运行/保存失效通过。
- 停止保留未发送输入，迟到结果不能替换制品。
- 一次修复演示、修复关闭后的错误保护、失败时保留预置保存版通过。
- Enter 发送、Shift+Enter 不发送、输入法组合输入不发送通过。
- 未处理的编辑阻止浮层关闭，可放弃再关闭。
- Markdown 粗体/引用/代码块可生成；HTML 标签转义、javascript 链接不创建、注入脚本未执行。
