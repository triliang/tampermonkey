## 本轮交付

- 正式 Preact 工作区改为 Chat：消息独立滚动、底部输入、单一制品栏、顶部快捷入口；代码/权限/版本/诊断按需进入浮层。
- 安全 Markdown 子集与代码词法高亮；展示系统处理状态、修复提示和流式 explanation，不展示模型内部逐字推理。
- Enter/Shift+Enter/IME 保护；生成与分析过程中可输入下一条，完成或停止后恢复；不会自动发出下一条。
- 点击发送直接生成，首次和模型变化不再额外确认；主动发送预览仍可用且不会请求模型。
- 代码单行/非连续行/Shift/键盘选择、引用替换/移除；准确版本/行号/快照绑定，200 行/32 KiB 守卫，引用纳入实际请求与预算。
- 后台核对工作区/版本/hash/逐行文本，旧版或伪造引用在模型请求前拒绝；成功清空待发送引用，对话保留历史附件。
- 单独添加/移除引用保留原有效试运行资格；已失效的凭证不复活；代码/权限/输入/目标变化和过期仍按原规则检查。
- 保留 R1 质量检查、修复预算、效果确认、服务互斥、CAS 和 V2 版本/GM/自动运行/导出/P7 服务。

## 已知边界与准出

- 生成/分析期间的下一条文字只缓存在当前挂载 UI；正常结束/停止后恢复并持久化。强制关闭侧栏/重载前尚未恢复的文字不保证恢复。
- 引用来自历史版本时保留快照、明确标记历史来源；发送拒绝并要求重新选择当前版本，暂不做自动行号重定位。
- Markdown 是安全子集，高亮是轻量词法展示；不包含完整 IDE、代码格式化或语法树编辑。
- 过程来自现有生成进度和检查结果；不伪造耗时阶段、完整思维链或视觉验收结论。
- 工具保存/自动注册/恢复仍按既有服务，不自动发布或替用户撤销正式权限。

## 左侧网页代码浮层增量（2026-10-15）

制品默认在左侧匹配网页打开宽版代码浮层，右侧聊天保持可输入。复用高亮/编辑/选行组件；添加引用后关闭左侧并聚焦右侧，保留正在输入的文字。高级操作回到侧栏。受限/未授权/注入失败时回退侧栏，不增加站点权限。

新增会话服务验证工作区、代码身份、主 frame、tab/document 与 CAS/互斥；小型会话元数据持久化以支持 SW 重建，不另存完整代码。真实 Chrome 的布局、焦点、剪贴板和 SW 实际停止仍按 [专项清单](./v2.1-page-code-preview-checklist.md)验收。

工程结果：38 文件、324 项通过；类型、lint、构建通过。证据独立存为 [page-code-test](./evidence/page-code-test.txt)、[typecheck](./evidence/page-code-typecheck.txt)、[lint](./evidence/page-code-lint.txt)、[build](./evidence/page-code-build.txt)、[源码/构建身份](./evidence/page-code-source-sha256.json)。测试限制 2 个 worker，避免本机高并发资源争用。未将 DOM/transport 替身结果标记为真实浏览器验收通过。

## 推理模式增量（2026-10-15）

全局推理默认开启，聊天底部可即时取消，AI 设置页可保存偏好；生成/修复/分析均跟随模式。发送快照绑定模式及有效协议，配置变化使旧预览/候选失效。推理原文不展示或进入脚本 JSON，reasoning_content 仅转为一次状态通知。自定义端点的自动识别、显式 thinking.type 与服务端默认边界见 [专项清单](./v2.1-thinking-manual-checklist.md)。

全量 **39 文件、330 项通过**；类型检查、lint、生产构建通过。证据：[测试](./evidence/thinking-test.txt)、[类型](./evidence/thinking-typecheck.txt)、[lint](./evidence/thinking-lint.txt)、[构建](./evidence/thinking-build.txt)、[源码身份](./evidence/thinking-source-sha256.json)。

并行测试中已有 1 MiB 流解析耗时用例一次为 77ms，超过其 50ms 阈值；保留 [当次日志](./evidence/thinking-test-contention.txt)。未放宽阈值，改为单 worker 重跑全量后通过。输入恢复相关用例还揭示结束状态先于工作区载入的窗口，已调整为恢复下一条文字后才结束生成/取消状态，避免编辑窗口中的文字被晚到载入覆盖。

自动证据为 fetch/transport/存储替身与 jsdom，不代表真实供应商或 Chrome 参数验收通过。可按推理专项步骤观察真实 SW Network；不归档认证信息。
