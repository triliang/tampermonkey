# iframe 广告点选优化验收

日期：2026-10-15。状态：正式实现与自动检查完成，CSDN 实页待人工验证。本轮没有可连接的 Tabbit 实例，不把 DOM 测试当成 CSDN 验收通过。

## 改动与边界

此前已有普通全屏覆盖层，但依赖页面 z-index 和命中栈，不能据截图唯一判定失败原因。本轮改用非模态 Popover 顶层覆盖，规避常规页面堆叠上下文；命中检测同步临时关闭覆盖层 pointer-events，查询后立即恢复。高亮矩形是独立 UI，不修改真实元素 class/style，避免污染选择器和目标指纹。

可选跨域 iframe 的**外框**及其所在父容器，不读取跨域 iframe 内部 DOM、不增加子域授权或全 frame 注入。DevTools 有浏览器级检查能力，扩展点选不是完整 DevTools 替代品。对“隐藏广告”任务，应选择能同时包含图片、广告标签和占位的最小完整容器。

## 1. 加载新代码

1. 在 `chrome://extensions` 重新加载鲁班（目录 `luban/dist`）。
2. **刷新 CSDN 网页**，关闭旧侧栏重新打开。仅重开侧栏不能保证已注入内容脚本替换为新代码。
3. 保持广告显示，点击底部「点选元素」。鼠标移到截图中右侧广告中央。

**预期：** 显示蓝色范围框和元素提示。若命中 iframe，提示含「iframe 外框」，无需把鼠标挪到广告边缘才可点选。

- [ ] 在广告中间、边缘和标签附近都能看到对应目标范围。
- [ ] 点击选中后，侧栏显示所选目标；不应跳到广告链接或打开新标签页。

## 2. 选择完整广告容器

1. 将鼠标停在广告上，先不要点击。
2. 按 **↑** 逐层选择父级，观察蓝框；选择刚好包住广告主体、标签和占位的最小容器。
3. 如范围过大，按 **↓** 返回上一层。
4. 按 **Enter** 确认；也可在原位置点击确认当前层级。
5. 展开侧栏范围入口，核对候选/模块范围。需要时选择完整模块、只读预览并确认策略。

**预期：** 可以选 iframe 外部 div；上下切换不修改网页，不会自动隐藏广告，也不会自动把整个右栏当成广告容器。

- [ ] ↑ / ↓ / Enter 正常；父级选择不扩大到 body/html。
- [ ] 当前层级提示与蓝框一致，确认后捕获的是当前层级，不退回 iframe。
- [ ] 选择器不包含 `__luban_picker_highlight` 等点选器 class。

## 3. 退出、滚动与普通元素回归

1. 再次开启点选，按 Esc。
2. 再次开启点选，滚动页面，观察高亮位置。
3. 点选普通标题、链接或图片，确认结果；随后正常浏览页面。

- [ ] Esc 清除所有点选浮层，不留下透明层挡住页面，未发送需求、不请求模型。
- [ ] 滚动/窗口变化后高亮跟随当前元素，不停留在旧坐标。
- [ ] 点选结束后页面链接可正常使用；普通元素点选不退化。

## 4. 广告隐藏效果

输入「隐藏我选中的这个完整广告模块，连同广告标签和占位一起隐藏，保留正文和相邻推荐」。生成后主动运行，再确认效果。

- [ ] 选对范围后，广告主体、标签和占位一起消失，正文及相邻模块保持。
- [ ] 若生成脚本选择范围仍不准确，通过当前工具继续反馈，不把“点选成功”当成“脚本效果验收通过”。
