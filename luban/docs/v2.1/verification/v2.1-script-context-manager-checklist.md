# 脚本附件与精简管理页验收

日期：2026-10-15。覆盖聊天自动携带完整脚本与独立脚本管理页。

## 1. 聊天自动携带当前脚本

1. 重载最新 `luban/dist`、重开侧栏。新建且尚未生成脚本时，输入区不应出现空脚本附件。
2. 生成脚本后，在输入框上方检查 `.user.js` 标签，点击可查看代码。
3. 发送下一轮修改要求；主动查看「发送范围」核对附件身份与完整代码。
4. 从「我的工具」选择已有脚本，再发送修改需求。
5. 手动修改当前草稿后再发送；同时附带选行引用测试一次。

- [ ] 已生成或选中的脚本自动随消息携带，用户无需手动选行或再次粘贴代码。
- [ ] 有草稿时携带当前草稿，否则携带当前保存版；文件名、版本、来源和实际代码一致。
- [ ] 发送中与发送后的用户消息均显示附件身份；历史附件显示来源版本，不把旧附件冒充当前文件。
- [ ] 选行引用与完整脚本同时存在，选行仅强调修改位置，不取代完整代码。
- [ ] 原保存版/上一版不会被自动额外附带；输入超预算时拒绝，不静默截断代码。
- [ ] A/B 工具隔离，切换工具后不携带上个工具的脚本。

实现采用 Chat Completions 正文中的完整代码及附件身份元数据，并非额外上传文件到供应商 Files API；代码只有一份，不因附件标签重复附带全文。

## 2. 管理列表

打开设置 → 脚本管理。

- [ ] 列出全部已保存脚本，可搜索、排序；显示名称、网站、更新时间和自动运行状态。
- [ ] 每行只有「查看 / 编辑」、自动运行开关、删除。
- [ ] 无聊天输入、历史会话、草稿列表、生成/分析入口、当前页运行或导出操作。
- [ ] 未保存的新制品仍在聊天草稿中，不冒充已保存脚本出现在列表里。

## 3. 查看、编辑与版本

1. 点击「查看 / 编辑」打开管理页代码浮层。
2. 核对当前代码，已有上一版时切换版本下拉框查看。
3. 点击编辑、修改、保留为未验证草稿；此时保存版应不变。
4. 在目标网站已打开并授权的前提下，点击「在网页试运行」。浏览器会切换到匹配网页。
5. 检查实际效果，返回管理页，再点击「效果符合，保存」。该动作会再次切到试运行网页以核对凭证。

- [ ] 查看/编辑过程中不显示聊天历史或选行添加到聊天按钮。
- [ ] 草稿关闭后仍保留，重新打开可继续；界面明确草稿未更新保存版。
- [ ] 未成功试运行不能保存；语法/权限/运行错误保留草稿并提示。
- [ ] 保存后当前版更新、上一版保留；恢复上一版须明确确认放弃当前草稿。
- [ ] 没有匹配网页或未授权时有提示，不直接绕过运行凭证保存代码。
- [ ] 脚本在其他窗口生成时管理页只读；旧 base 或版本冲突时不覆盖新保存版。

## 4. 开关与删除

- [ ] 开启自动运行时按需请求网站授权，拒绝不伪装为开启成功；关闭不额外请求权限。
- [ ] 注册失败时显示错误，并重新读取真实脚本状态，避免列表永久停留旧状态。
- [ ] 删除需要明确确认；取消不改变脚本，确认后脚本从列表移除。
- [ ] 删除仍沿用原后台服务处理关联数据/注册，不只移除列表行。

## 列表紧凑布局补充

- 搜索与排序始终同排，搜索占剩余宽度，排序固定紧凑宽度。
- 每个脚本两行：第一行名称与查看/编辑、删除图标；第二行网站、简短更新时间、唯一自动运行勾选框。
- 不再重复显示自动运行文字状态或单独开关按钮；悬停图标有提示，按钮保留无障碍名称。
- 窄侧栏长名称/网站使用省略显示，悬停可查看全文；图标、勾选框不被挤出。

列表最新调整：脚本条目改为单行，依次为名称、网站、简短更新时间、自动运行勾选及操作图标。窄区域优先隐藏更新时间，极窄区域隐藏网站（查看详情仍可访问脚本信息），名称省略显示，保持勾选和图标可操作。

自动运行最新调整：改为可点击电源图标，绿色表示开启、灰色表示关闭；悬停显示当前状态和点击后的动作。按钮带 switch 角色与 aria-checked，不只依赖颜色传达状态。验证点击切换后状态更新，授权拒绝不显示为成功开启，忙碌时禁用。

列表信息最新调整：名称、网站、更新时间靠左连续排列，之间用细分隔线区分；名称保持蓝色，网站/时间保持灰绿色。时间显示完整日期及 24 小时时分秒，右侧图标维持原状态颜色；窄区域文字省略，悬停时间可查看完整值。
