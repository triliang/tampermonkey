# 模型推理过程展示验收

日期：2026-10-15。此项将原先“仅推理状态”升级为展示模型实际返回的 `reasoning_content`；不推测模型未返回的内部过程。

## 操作与通过标准

1. 重载最新 `luban/dist`，重开侧栏，确认「推理」已勾选。
2. 发送需求。模型返回推理字段时，应出现独立「推理中 · 模型返回」区域，流式更新，支持安全 Markdown，内容区限高可滚动。
3. 生成完成后推理区域自动折叠；点击「推理过程」可展开。最终说明、代码与推理分别展示，草稿代码不得混入推理文字。
4. 如发生一次受控修复，应分别保留「首次请求」「修复请求」推理，不覆盖第一段。
5. 关闭重开该工具，成功生成的推理附件可在对应助手消息中查看。再次发送时，实际请求历史只包含原有正文，不回传推理附件。
6. 开启分析此页并确认发送，页面分析的推理应独立展示；不得混入建议 JSON，也不自动生成/运行。
7. 模型未返回推理字段时不编造内容；关闭推理后按端点实际响应展示，不把“开关打开”当作一定有可展示文本。
8. 每次请求最多展示 64 KiB UTF-8 推理，超出提示截断且不切坏中文字符；正文继续处理。成功对话附件仍受原 1 MiB 容量约束，容量不足时省略历史推理并明确标注，当前会话可继续查看已有流式内容。
9. 原始 HTML/脚本/危险链接不执行，外部图片不自动加载；取消或失败保留已收到推理供当前侧栏查看，但不承诺跨重开保留失败/取消推理。
