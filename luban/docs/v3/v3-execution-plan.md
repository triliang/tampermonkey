# 鲁班 V3 执行计划与阶段验收标准

版本：R2。更新：2026-10-17。状态：S0、S1 本轮个人试点验收完成，分别保留用户延期的干净环境与双 Chrome profile 项；S2 实现与自动验证完成，真实 Codex/Cursor 业务联调按用户选择暂缓，先交付实现和清单，阶段未验收关闭；S3–S5 实现与隔离自动验收完成（扩展 380 项、Bridge 56 项及构建/包检查通过），最终真实验收统一由用户执行。详见各阶段执行记录。

依据：[PRD](./v3-prd.md)、[C4 技术方案](./v3-technical-design.md)、[需求范围](./v3-product-requirements.md)。验收执行与证据填写见 [V3 验收清单](./verification/v3-acceptance-checklist.md)。

## 1. 已确认执行基线

用户本轮确认首发 macOS，并要求其余按建议项执行。落为下列基线：

| 决策 | 本期执行规则 |
|---|---|
| 首发平台 | macOS；具体系统最低版本、arm64/x64 架构矩阵在 S0 实测冻结，未验证架构不宣称支持 |
| 分发 | 先个人本地加载扩展试用；本机安装包内置 Node 运行时，不要求试用用户自行安装 Node |
| 执行方 | 首批 Codex App Server；用户在官方程序中安装/登录/授权，项目负责版本选择、协议适配与验证 |
| MCP | Codex、Cursor 分别作为外部客户端验证；不将 Cursor 会话适配纳入 P0 |
| 飞书 | 自建应用机器人、单用户单聊、一应用连接一台电脑；用户提供应用和权限条件，Secret 在专用配置录入 |
| 页面授权 | 指定页面/工具；导航或浏览器重启后失效；不默认开放持久整站或全部标签页权限 |
| 网页写操作 | 必须在鲁班本地确认；外部请求不能直接保存、恢复、删除或开启自动运行 |
| 数据保留 | 任务记录默认 30 天，诊断默认 7 天；容量上限、单条预算及清理策略在 S0 冻结 |
| lark-cli | 保持 P1；P0 用官方 SDK，不同时引入重复事件监听 |

保留期限不适用于用户保存的工具、当前草稿或上一版。活动任务、未决执行结果、未完成发送和去重记录不能因普通历史清理而失去一致性保护；详细策略见 S0/S1。

个人本地试用不等于绕过权限与安装验证，也不承诺公开发布。公开上架、开机常驻、多平台和 lark-cli 扩围单独安排。

2026-10-16 用户调整：干净 macOS 用户环境验证（S0-A1/M06 及关联操作）因成本较高，本轮暂缓，不阻塞后续个人试用开发；保留同用户迁移安装通过证据，不能宣称干净环境已通过。公开发布前补验；其他门槛不因此自动豁免。

## 2. 执行方式与阶段依赖

按 S0–S5 形成可验证增量。每阶段完成相关实现、必要测试、修复和证据整理后再关闭阶段，不以提交代码或构建成功替代业务验收。

| 阶段 | 目标 | 前置依赖 | 交付出口 |
|---|---|---|---|
| S0 | 消除关键接入与安装不确定性 | 仓库可读；真实对接条件逐项就绪 | 依赖/协议/安装/兼容矩阵冻结 |
| S1 | 本地连接、任务与授权基础 | S0 本机通道与存储结论 | 安全连接、可恢复状态、原链路不受影响 |
| S2 | MCP 浏览器能力闭环 | S1 + S0 MCP 客户端验证 | 真实外部客户端读取、提交、确认试运行 |
| S3 | Codex 会话执行闭环 | S1 + S0 Codex 验证 | 真实生成、多轮修改、取消与草稿保护 |
| S4 | 飞书发送与任务闭环 | S1/S2/S3 + 飞书条件 | 单聊任务、本地确认、独立结果回传 |
| S5 | 集成与个人试用交付 | S1–S4 阶段出口通过 | 可安装试用包、完整验收及已知限制 |

S2/S3 在依赖具备后可独立推进；先完成 S2 的页面/运行网关便于 S3 复用。此处描述研发依赖，不要求使用多 Agent。

技术门槛不是每阶段向用户重新索取“继续”的审批。缺外部条件时，推进不依赖该条件的模块，并标记相关真实验收为待验收；不能凭模拟结果关闭阶段或声称 V3 完整交付。

### 4.2 阶段验收标准

| ID | 验收操作 | 必须满足 |
|---|---|---|
| S1-A1 | 首次连接、配对、撤销；未配对客户端尝试调用 | 新连接没有页面权限；撤销阻止新访问；自报客户端名称不能认证 |
| S1-A2 | 两个浏览器 profile 同时连接，切换活动页 | 请求只到绑定 profile/document；不转到其他活动页 |
| S1-A3 | 发送破损帧、超限帧、错误版本、未知方法及多帧 | 拒绝并返回可定位错误；进程不崩溃，不截断后当完整结果 |
| S1-A4 | 从 IDB v1 升级；模拟旧窗口阻塞及迁移失败 | 原模型/工具/草稿/上一版/自动运行保持；不清库重建 |
| S1-A5 | 侧栏与外部任务竞争同一 workspace；旧 epoch 迟到提交 | 仅有效 owner+版本可写；冲突候选可查看，最新草稿不丢 |
| S1-A6 | 导航、关页、SW 重启、浏览器重启、撤销权限 | 原确认/授权按规则失效；不使用活动页回退，不重放写操作 |
| S1-A7 | 执行后、回执写入前故障注入并重连 | 显示结果未知；无自动二次执行，记录足以人工核对 |
| S1-A8 | 确认重复点击、外部伪造决定或过期 Approval | 一次消费；非扩展 UI 无法批准；页面/版本/授权变化需重新确认 |
| S1-A9 | 人工推进时间或注入过期样本，触发容量超限 | 30 天任务/7 天诊断按规则清理；活动与未知操作保护不丢；超限有可读处理 |
| S1-A10 | Bridge 未安装/断开时使用原模型链路 | 原生成、试运行、保存/恢复可用；无自动切换或额外授权 |

出口：所有写路径纳入相同授权/CAS/Approval 网关；安全或迁移用例失败不能进入正式外部写操作接入。

## 6. S3：本地 Codex 会话

2026-10-17：用户要求后续阶段连续实现、自动验收，最后统一手动验收。本阶段实现已落地；[自动结论](./verification/v3-s3-auto-verification-2026-10-17.md)、[手动列表](./verification/v3-s3-manual-checklist.md)、[执行记录](./verification/v3-s3-record.md) 已建立。真实验收未关闭，不以替身结果计通过。

### 6.1 任务与交付物

- S3-T1：拆分执行方无关 Envelope/产物验收，保持原模型分支；实现 AgentAdapter。
- S3-T2：Codex 专用 app-server 子进程、thread/turn 映射、事件标准化及停止协议。
- S3-T3：执行方选择、历史衔接说明、阶段摘要、完整结果解析和候选检查。
- S3-T4：纳入任务租约、页面/版本复核、迟到保护及原修复预算；不扩大 Agent 文件/终端权限。
- S3-T5：连接/登录/版本/额外审批异常展示；专用工作目录与子进程安全启动。

### 6.2 阶段验收标准

| ID | 验收操作 | 必须满足 |
|---|---|---|
| S3-A1 | 真实 Codex 新建工具，连续两轮修改 | 每轮沿用当前草稿和约束；与其他工具不串，最终可试运行并保存 |
| S3-A2 | 手动编辑后继续修改，切到第三方模型再切回 | 最新基线保留；历史不足明确告知，不自动重发或切换执行方 |
| S3-A3 | 不完整/非法产物、质量失败、断连与超时 | 半成品不成为有效草稿；已有草稿/保存版不被覆盖 |
| S3-A4 | 流式处理期间停止，延迟到达 delta/完成事件 | 先显示停止请求，收到终止确认后结束；迟到不能覆盖 |
| S3-A5 | 导航/撤销授权与 Agent 完成同时发生 | 无效上下文结果被阻止，执行前重新核验页面/版本 |
| S3-A6 | Agent 请求额外文件/终端权限；CLI 未登录/不兼容 | 不自动批准；引导用户在官方入口处理，展示真实不可用原因 |
| S3-A7 | 退出并恢复集成创建的线程，或恢复失败 | 能继续或明确以最新基线新建；不接管用户桌面其他聊天 |

出口：PRD L01–L07 通过，并记录 CLI/模型/权限配置与真实轮次结果；原链路费用文案不能错误套到 Agent 内部调用。
