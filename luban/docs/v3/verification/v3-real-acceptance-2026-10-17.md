## 联调中发现并解决的客户端配置问题

2. Codex exec 默认 never 审批使候选提交被拦截。读取已成功但没有提交任务，不能当提交通过。后续仅用本次进程的指定 MCP 写工具批准，鲁班本地执行确认仍保留。[Codex 官方逐工具配置](https://developers.openai.com/codex/config-reference)。
