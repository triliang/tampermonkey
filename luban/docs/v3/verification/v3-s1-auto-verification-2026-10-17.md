## 人工项目（以下保留最初步骤；当前状态以最新反馈为准）

### M02：正式配对撤销与重新配对

这会更换当前正式配对身份。本轮未操作正式凭据撤销；旧凭据拒绝已在独立 IPC 环境自动通过。

1. 在连接与集成中记下配置档标识，点击撤销配对。
2. 应显示未连接、未配对，页面授权为空。
3. 主动点击连接，重新配对成功后，配置档标识应改变。

### M03：两个真实 Chrome 配置档

1. 在另一个 Chrome 配置档加载同一 `luban/dist/`，确认扩展 ID 相同后连接；若 ID 不同，反馈，不覆盖注册。
2. 两个鲁班配置档标识应不同。
3. 只在 A 的公开测试网页侧栏授权，刷新两边列表：A 有该页，B 为空。
4. B 断开、重连后仍为空，A 的授权不受 B 影响；最后撤销 A 的测试页授权。

这只能确认真实 Chrome 的授权列表隔离；外部客户端读取/执行还需后续入口开放再验。

### M05：实际旧数据

核对你原有工具、草稿、保存版/上一版、对话及自动运行开关是否保持。人工核对依赖你知道升级前的数据，测试样本不能代替。若该配置档本来没有旧数据，记为“不适用”，不要记“通过”。不要清库或卸载扩展。

### M10：完整 Chrome 重启

刷新与关页已自动验证，不用重复。方便时在公开测试页授权，完整退出并重开 Chrome、重新连接 Bridge；旧授权应为空。此项会影响其他打开的标签页，所以本轮没有自动退出整个 Chrome。
