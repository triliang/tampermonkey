## Demo 使用方法

顶部切换场景会重置演示数据：

1. 本地 Agent 会话：点击示例需求或输入文字 → 发送 → 试运行 → 确认 → 观察左侧 → 效果符合并保存。继续发送可修改；代码浮层可查看保存版和恢复上一版。
2. MCP 外部调用：左侧读取授权页或提交草稿与运行申请 → 右侧确认或拒绝。连接与集成中可以撤销授权，再提交请求验证阻止行为。
3. 飞书机器人任务：左侧发起任务 → 右侧确认运行 → 左侧查看模拟回复。手机窄屏使用输入区的“模拟外部请求”触发示例。

结果提供发送飞书入口，可预览目标和编辑正文。顶部“故障模拟”可切换断连、页面失效、回复失败及发送结果未知。“任务记录”展示任务与回传的独立状态。

所有服务和检查均为模拟；无网络请求，不发送真实消息。Demo 的已连接初态用于评审，不是新安装默认。名称不构成第三方兼容声明。刷新后数据重置。代码示例仅作用于演示广告，不是实际网页选择器适配。
