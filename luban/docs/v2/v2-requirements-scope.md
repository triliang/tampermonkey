> 依据：[功能评审](./feature-review.md)、[三家细化调研](./customaise-vibemonkey-scriptgenie.md)及本次产品方向分析。竞品事实沿用 2026-10-11 材料，未重新调研。

## 1. 产品定位与本期决策

**用户用一句话为当前网站创建一个小工具，现场试用，持续修改，保存后再次访问自动生效。**

v1 的点选、生成、确认运行、本地保存和手动再运行是已有基线。V2 补齐从创建到长期维护的闭环：

描述需求 → 生成并解释 → 确认试运行 → 继续修改 → 保存并设置自动运行 → 下次生效 → 停用或恢复上一版。

### 参考对象与取舍

| 对象 | 借鉴方向 | V2 落点 |
|---|---|---|
| Customaise | 产品围绕当前网站和可管理的脚本组织 | 默认描述页面、可选点选、当前脚本明确、确认应用、可恢复、可导出 |
| VibeMonkey | 最小自然语言生成链路和标准产物 | 整页生成、有限页面上下文、标准 `.user.js`；不照搬粗粒度计数摘要 |
| ScriptGenie | 一条脚本的持续迭代 | 独立对话、编辑草稿、更新已有脚本、恢复上一版 |

运行脚本是基础能力。差异化需要通过当前页生成质量、修改成功率和持续复用验证，不能仅以“当场运行”宣称领先。

### 相对旧范围的调整

- “脚本独立管理、围绕脚本继续修改、恢复上一版”进入核心范围。
- 简单代码编辑、标准导出从应做项提升为核心范围。
- 同站自动运行与恢复能力共同交付，避免错误持续生效却无法恢复。
- 分析此页、自定义模型端点排在核心闭环之后。
- 完整版本历史仍延后；本期的“恢复上一版”不等于完整版本管理。

## 2. 用户与优先场景

| 用户 | 场景 | 做成的结果 |
|---|---|---|
| 普通用户 | 改样式：暗色、字号、布局 | 不点选即可生成，下次访问保持效果 |
| 普通用户 | 隐藏干扰：广告或无关模块 | 可点选定位，结果不准确时继续描述修改 |
| 高频网站使用者 | 增强展示：突出价格、状态、关键字段 | 保存为独立工具，可继续调整和停用 |
| 高频网站使用者 | 提取当前页内容：链接、图片地址、表格数据 | 在当前页确认执行，结果可检查；不扩展到翻页采集 |
| 开发者 | 修正选择器或小段逻辑 | 修改代码后试运行、保存更新，失败可恢复 |

刷新、监控等已有快捷意图不作为本期主推场景；不增加后台定时调度承诺。

## 3. 范围与优先级

### 核心范围：缺一项不能称为完整 V2

| ID | 能力 | 最小交付 |
|---|---|---|
| F1 | 整页描述与可选点选 | 直接输入意图，或点选后精确修改 |
| F2 | 脚本独立管理 | 名称、网站、当前保存版本、独立对话、启停与修改入口 |
| F3 | 持续修改和简单编辑 | 修改当前脚本的草稿，不覆盖已保存版本 |
| F4 | 确认运行与失败修复 | 说明预期效果、确认执行、带错误继续修改 |
| F5 | 恢复上一版 | 更新前保留一个可恢复的已保存版本 |
| F6 | 同站自动运行 | 明确开启、展示范围、下次生效、可关闭 |
| F7 | 标准导出 | 导出当前已保存版本，可在目标脚本管理器验证运行 |

发布要求：发送内容可见、脱敏与安全检查、移除生产自检、模型设置说明准确，以及真实场景验收。

### 核心完成后增强

- 手动“分析此页”：最多四条建议，采纳后进入生成；不随页面加载自动请求模型。
- 自定义 OpenAI 兼容端点：Base URL、模型名、Key；仅支持 Chat Completions 兼容接口。

增强项不阻塞核心版本验收，也不能替代任何核心项。若本次发布包含增强项，须单独记录验收结果。

### 本期不做

通用聊天、独立翻译/总结/搜索入口、跨站代理、录制和工作流画布、市场、账号与云同步、脚本导入、完整版本时间线和固定版本、Monaco 等完整编辑器、路径级和跨站匹配、扩充 GM API、`@require`、多语言、AgentScript 与 MCP。

## 4. 产品形态与页面要求

### 首页与当前网站

默认提供需求输入，提示“你想怎么改这个网站”；点选是辅助入口。展示当前主机名及匹配该网站的已保存脚本，可进入修改或关闭自动运行。最近脚本与当前站脚本需区分，避免误在别的网站运行。

非普通网页、无法采集上下文、跨域 iframe 等情况下，说明当前限制；不把上下文缺失表现为生成成功。生产首页不显示通信自检。

### 脚本工作区

显示当前脚本名称、适用网站、已保存版本与待保存草稿状态。对话属于该脚本；新建脚本不得显示上一条脚本的代码和消息。主要操作为继续描述、查看/编辑代码、试运行、保存更新、放弃草稿、恢复上一版。

离开存在未保存修改的工作区时，提供保留草稿、放弃修改、继续编辑。重新打开可找回保留的草稿；草稿不用于自动运行或默认导出。

### 脚本管理

列表展示名称、主机名、自动运行状态和更新时间，默认按更新时间倒序。支持按名称或主机名查找；每条提供打开修改、当前页运行、自动运行开关、导出与删除。当前页面不匹配时不执行，并提示打开适用网站。

删除前明确将移除脚本、对话、草稿和恢复副本，同时停止后续自动运行。已产生的页面效果通常需要刷新清除。

## 5. 功能需求与验收

### F1 整页描述与可选点选

**用户结果：** 用户不用先理解 DOM 元素即可创建工具。

**规则：** 默认整页描述；点选用于“就改这一块”。提交前展示采集范围。整页摘要应包含有限的相关结构和可定位线索；不能仅凭按钮数量让模型猜选择器。保持既有采集上限和脱敏约束。

**验收：** 不点选完成暗色或信息增强；点选完成隐藏指定模块。两条链路都经过预览与确认，取消点选后可继续整页输入。

**不做：** 跨页面任务和无限制采集整页 HTML。

### F2 脚本独立管理

**用户结果：** 用户知道自己在修改和运行哪一个工具。

**规则：** 首次保存形成独立脚本；模型建议名称，用户可修改，名称去除首尾空白后不能为空。修改已有脚本默认更新原脚本，不产生新记录。新建草稿、不同脚本的对话和运行错误相互隔离。保存失败不得显示成功或丢失草稿。

**验收：** 创建 A、B 两条脚本，分别修改、关闭面板再打开，代码、消息和状态不串；旧脚本升级后仍可打开和运行，无历史对话时显示空状态。

**不做：** 文件夹、协作权限和云同步。

### F3 持续修改与简单编辑

**用户结果：** 用户说“再把字号调大”即可调整已有工具。

**规则：** 修改基于当前草稿；没有草稿时基于当前保存版本。生成前说明会发送当前代码、相关对话及新采集的页面上下文。历史对话需有限裁剪，当前代码和本次需求不得丢失。取消、生成失败或运行失败均不覆盖保存版本。代码可在普通文本编辑区修改；手动修改后继续对话以修改后的代码为准。

保存更新必须经过该草稿的确认试运行；运行后再次改动代码，需重新试运行。安全检查在实际运行与保存时生效，手动编辑不能绕过。

**验收：** 对已保存暗色脚本追加字号调整，原有暗色保留；手动改选择器后继续对话不退回旧代码；取消生成和放弃草稿后原版本仍可使用。

**不做：** 通用聊天与完整 IDE。

### F4 确认运行与失败修复

**用户结果：** 用户能判断是否应用，并能在失败后继续修复。

**规则：** 预览解释预计改动、适用网站、已识别风险。每份新建或修改草稿首次试运行均须确认。仅执行返回成功只能说明脚本执行完成，不能冒充已经验证视觉效果；展示预计效果并让用户检查。运行报错可携带当前代码、有限错误信息和页面上下文继续修改；结果不符合预期时用户也可直接反馈。

重复试运行前提示已有页面效果可能残留，需要刷新后验证；刷新前保留草稿。生成尽量可重复执行，验证不得出现重复插入组件或重复注册操作。

**验收：** 未确认不执行；错误后修复仍属于同一脚本；脚本执行完成但未找到目标时，不显示“已隐藏目标”等未经验证结论。

**不做：** 像素级对比和任意脚本的即时撤销。

### F5 恢复上一版

**用户结果：** 改坏后可以恢复可用代码。

**规则：** 更新已有脚本成功时，原保存版本成为唯一“上一版”；试运行和失败保存不改变恢复副本。首次保存无上一版，入口禁用并解释原因。恢复前展示将替换当前版本，有草稿时先处理草稿。恢复代码和对应说明，不回退对话、GM 存储、权限或用户的自动运行开关。

恢复成功后保留恢复前版本为上一版，允许恢复操作本身被撤回。开启自动运行的脚本，保存更新和恢复均需同步替换后续自动运行代码；替换失败不得显示整体成功，也不得丢失当前可用版本。已打开页面提示刷新以应用恢复版本；外部请求等副作用不可撤销。

**验收：** A 更新为 B，刷新运行 B；恢复 A 后刷新运行 A；自动运行开关状态不变。模拟更新或恢复失败，原保存版本和恢复入口仍可用。

**不做：** 完整历史、命名快照、版本分支。

### F6 同站自动运行

**用户结果：** 下次访问无需打开扩展即可生效。

**规则：** 自动运行默认关闭，保存与开启是两个明确动作，可在保存时选择开启。范围为当前准确主机名的 HTTP/HTTPS 页面，即 `*://主机名/*`，不含子域扩展；开启前说明会覆盖该主机名下所有路径。拒绝站点权限不影响保存，但自动运行保持关闭。

已有脚本升级后不得默认开启。关闭只阻止后续运行，不删除脚本、不撤销当前页面效果。删除脚本停止后续运行。权限被撤销或运行能力不可用时显示实际不可用状态，不保留误导性的“运行正常”。自动运行失败应能查看最近错误并进入修改。

只在完整页面加载时运行；站内无刷新跳转不承诺再次注入。同站多条脚本分别管理，不承诺消除相互冲突。

**验收：** 保存并开启后，不点扩展图标新开匹配页面即生效；不匹配网站、拒绝权限、关闭开关、删除脚本后均不再注入。更新或恢复后新开页面运行对应保存版本。

**不做：** 路径规则、跨站规则和后台定时调度。

### F7 标准导出

**用户结果：** 用户能带走已保存的小工具。

**规则：** 默认导出当前已保存版本，存在草稿时明确提示导出不含未保存修改。文件包含标准 UserScript 头、名称、匹配规则、实际使用且支持的授权、运行时机和正文。代码不能依赖鲁班私有桥才能产生核心效果；不导出 Key、对话、页面快照或 GM 存储数据。导出的脚本在其他管理器安装后按其规则执行，不继承鲁班的关闭状态，导出时说明。

**验收：** 至少以样式修改和使用 GM 存储的脚本，在 Tampermonkey 中导入测试，确认匹配和核心行为可用；记录浏览器、管理器版本及兼容限制。不能只检查文件后缀和头部。

**不做：** 导入和全量运行时兼容承诺。

## 6. 脚本信息与状态规则

| 信息 | 规则 |
|---|---|
| 身份与名称 | 每条脚本独立身份；名称可修改，不以名称关联对话 |
| 网站与匹配规则 | 新建从当前页产生；修改中不自动扩大网站范围 |
| 当前保存版本 | 唯一用于自动运行和默认导出的版本 |
| 草稿 | 新生成或手动编辑结果；保存前不替换现行版本 |
| 上一版 | 最多一个完整代码与说明副本；首次保存为空 |
| 对话 | 属于当前脚本，包含需求、修改说明与必要错误反馈 |
| 自动运行状态 | 默认关闭；区分用户开启意愿与权限/注册失败状态 |
| 时间与运行反馈 | 展示更新时间、最近可获得的运行结果；执行完成不等于效果验证 |

本期保存与恢复不自动迁移或回退脚本自身的 GM 数据。旧脚本按现有内容作为当前保存版本，草稿、上一版与对话为空，自动运行关闭。

## 7. 主要用户流程与异常

1. **创建：** 打开当前网站 → 输入需求或点选 → 查看发送内容 → 生成预览 → 确认试运行 → 检查效果 → 命名保存 → 可选开启同站自动运行。
2. **修改：** 打开已保存脚本 → 继续描述或编辑代码 → 生成/编辑草稿 → 确认试运行 → 保存更新 → 原版成为上一版。
3. **修复：** 查看运行错误或反馈效果不符 → 带当前代码继续修改 → 再试运行；失败时保留现行版本。
4. **恢复：** 查看上一版 → 处理未保存草稿 → 确认恢复 → 更新后续运行版本 → 刷新页面验证。
5. **停用与带走：** 从当前站脚本或列表关闭自动运行；导出已保存版本；需要时删除。

| 异常 | 用户可见处理 |
|---|---|
| 未配置 Key、断网、限流或模型失败 | 说明原因并保留需求与草稿；本地脚本管理和恢复仍可用 |
| 当前页面与脚本网站不同 | 可查看和编辑，运行需打开匹配网站；不把新网站上下文混入请求 |
| 采集失败或 iframe 上下文不完整 | 显示限制，允许重新采集或调整目标 |
| 保存、恢复或自动运行替换失败 | 保留旧版和草稿，显示未完成，允许重试 |
| 页面已有旧版效果 | 提示刷新验证，不能声称代码恢复已经撤销所有副作用 |

## 8. 发布基线与边界

Chrome / Chromium、Manifest V3、仅中文、BYOK、扩展直连、无自建后端。GM 能力沿用 v1 白名单。

生成前可查看实际将发送的脱敏 URL、标题、采集范围、有限页面摘要；修改时增加脚本代码和相关对话。展示内容必须与实际请求一致。禁止采集或发送密码值、Cookie、localStorage 与扩展 Key；页面文本和用户手输仍可能包含敏感信息，不承诺“绝无敏感信息”。隐私页说明外部模型接收这些内容及用户检查方式。

沿用既有执行确认和安全扫描，不把静态扫描表述为完整沙箱。Key 存储说明与实现一致，不把混淆称为加密。

生产移除开发自检；新安装默认引导按量付费，保留已有用户设置。模型条款沿用既有风险记录，发布前复核，不在本文声称已经核实最新条款。

## 9. 验收与度量

### 核心出口

沿用 v1 的 10 个场景、10 个站点基线：一次生成可运行至少 7/10，至少 8/10 站点能注入。记录真实意图、入口、生成与执行结果、耗时和失败原因，不以填写表格代替达标。

在此之外必须完成：

- 四类优先场景分别验证整页或点选入口。
- 一条脚本走通创建 → 修改 → 保存更新 → 新开页面自动运行 → 恢复上一版 → 刷新验证 → 停用。
- A/B 脚本对话和草稿隔离；取消和保存失败不覆盖旧版。
- 自动运行拒绝权限、权限撤销、关闭、删除和升级旧数据均符合规则。
- 样式及 GM 存储两类脚本导出后通过目标管理器测试。
- 未确认不运行；手动编辑仍执行安全检查；展示发送内容与实际请求一致。

验收记录写入 `v2-acceptance-record.md`，包含环境版本、结果和已知限制；未完成不得宣称 V2 已交付。

### 产品观察

观察不点选完成率、保存率、自动运行开启率、7 日内再次生效且未被停用的比例、继续修改成功率、恢复使用情况、导出成功率。上述指标暂无新增数值目标。

本期不引入云端统计，采用有同意的人工试用记录或本地验证记录。不能从开发者单次测试推导真实留存。若反复停用或恢复，先定位生成质量与修改可靠性，再增加建议和模型能力。
