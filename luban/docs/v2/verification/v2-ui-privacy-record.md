## 交付

- ScriptLibrary 支持名称/host 不区分大小写搜索，默认更新时间降序，另可按名称/网站排序；区分整个工具箱为空与搜索无结果。
- 列表显示准确网站、更新时间、自动运行状态，提供打开修改、当前页运行、启停、保存版导出和删除。非匹配网页运行禁用且有解释；旧宽规则保留手动匹配路径，不能直接开启自动运行。
- 设置页脚本管理复用同一 App/工具库/工作区，而非再建版本管理逻辑。设置页没有目标网页时不能错误执行到扩展页，但仍可编辑、管理、恢复和导出。
- 已确认准确主机的保存版手动运行使用文档定向试运行执行器和 typed GM delta，保留 null 与 delete 区分；旧宽规则仍保留兼容手动运行入口。
- API Key 默认密码遮挡，支持显示/隐藏。新安装仍使用已有 DEFAULT_SETTINGS 的按量付费默认值；旧设置读取合并默认值，不覆盖现有配置。
- 隐私标签替换占位内容，说明直接模型请求、实际 payload 范围、本地业务数据、设置 sync、Key local/base64 不是加密、MAIN 边界、删除副作用、导出独立性和计费/外部条款。
- 增加清晰 focus-visible、按钮换行、工具库输入尺寸与弹窗最大宽度。生产页面不加入夹具故障开关、通信自检按钮；保留真实自动运行只读诊断与模型测试连接。
