## 4. 最终构建的完整生命周期

在 localhost 新建专用工具，需求为把 `#result` 显示为 `P6 A`：

1. 生成 → 试运行 → 保存为 `P6 生命周期`，确认页面显示 A。
2. 继续修改为显示 `P6 B`，试运行并保存更新。
3. 开启自动运行，新开 localhost 页面，不点图标，应显示 B。
4. 打开工具，恢复上一版 A，刷新目标页面，应自动显示 A。
5. 再恢复上一版，应回到 B；刷新应显示 B。
6. 编辑草稿为 C，不试运行、不保存；新开页面仍应显示 B。
7. 停用工具，再开新页应保持 WAITING；草稿 C 和保存版 B 仍可打开。

**预期：** 页面实际效果与保存版一致；草稿不参与自动运行，恢复只交换 current/previous，停用不删除数据。

- [x] 创建→修改→保存→自动→恢复→刷新→停用完整通过

## 5. 工作区、版本凭证、错误与并发

1. 新建 A、B 两个 localhost 工具，各写不同代码和需求；切换 A→B→新建→A，确认代码、输入、对话与草稿不串联。
2. 在 A 修改草稿，离开时选保留再重开，草稿存在；再修改并选放弃，返回保存版。
3. 试运行成功后修改代码或 GM 权限，不重新试运行直接保存，应拒绝或禁用保存；重新试运行后才可保存。
4. 手改代码加入可识别文字，再要求模型继续修改；发送预览应包含手改基线，生成后仍保留原功能。
5. 在专用草稿手改为 `throw new Error('P6_EXPECTED_ERROR')`，试运行应显示错误，不能保存为成功版；要求修复时检查预览中失败代码和错误上下文。执行无异常时也不能宣称页面效果已人工验证。
6. 对带面板的工具在同页重复运行两次，组件数量及监听副作用不重复。
7. 在侧栏和设置页同时打开同一工具。入口一修改并提交，入口二保持旧状态再提交；旧提交应报冲突，不能覆盖新版本。重开入口二后可看到最新版本。
8. 生成确认前切到不同 host；确认后生成过程中再导航。旧页面上下文不得用于新页执行或写成新页工具；应提示重新采集或丢弃过时结果。
9. GM 工具写入数值后更新/恢复代码，再读取；数据不随恢复回退。首次保存没有 previous，试运行、改名和失败不能凭空轮换 previous。

**预期：** 无丢失、串联、旧凭证保存或跨页误执行。
