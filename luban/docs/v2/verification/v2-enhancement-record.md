## E1 分析此页

- 设置中独立开关，默认关闭；侧栏主动点击采集、预览实际消息，再确认发送。页面加载不调用分析模型。
- 分析只发送脱敏后的有限页面摘要和分析指令，不携带工具代码、对话、GM 或 Key；预览和执行使用后台保存的同一消息。
- 最多四条 title/intent 建议；非法/残缺结果不出现可采纳项，不执行返回代码。
- 建议采纳仅进入需求输入框，再走既有预览生成、试运行及保存链路。
- 后台预览单次使用、有时效；前后核对文档身份和模型配置，重复请求、取消、页面变化和迟到结果受保护，不写当前工作区。
- 设置开关需保存，已打开侧栏重新打开后生效。分析预览存于 SW 内存，重启后失效并提示重新采集，不自动恢复请求。

## E2 自定义 OpenAI 兼容端点

- 独立开关及 URL/模型配置。只接受 HTTP/HTTPS Base URL，不接受 URL 凭据、查询参数、片段或完整 /chat/completions 地址。
- 保存/测试连接时由用户手势请求准确协议与主机权限；拒绝时旧配置不切换。Chrome 主机权限覆盖路径和端口，实际 HTTP 请求仍使用填写的 URL。
- 自定义不要求 MiMo Key 前缀，不强制 MiMo thinking/api-key 字段，使用指定模型与 Bearer 认证；原 MiMo 路径保留。JSON 模式和 Chat Completions 仍要求服务支持，不宣称任意 API 均兼容。
- 自定义 Key 与原 MiMo Key 分开存于 local/base64，预设模型与计费配置保留；关闭增强不自动撤权或清除 Key。非敏感配置仍在 sync。
- HTTP 错误不把供应商原始错误体回显给用户，避免回显认证信息。测试连接入口仅允许可信扩展页。
