### 1.2 GM 存储工具

> 创建标准 GM 存储测试工具，声明 GM_getValue、GM_setValue、GM_deleteValue 权限，记录运行次数，验证 null 和删除，将结果写入 #result。

```js
const before = GM_getValue('p5_visits', 0);
GM_setValue('p5_visits', before + 1);
GM_setValue('p5_nullable', null);
GM_setValue('p5_deleted', 'temporary');

  before,
  visits: GM_getValue('p5_visits', 0),

});
```

### 5.2 旧函数式 GM_info

另建专用工具，让模型声明 GM_info，然后用下面代码试运行并保存：


**预期：** 鲁班兼容路径可以运行旧函数式调用，但导出必须阻止，并提示重新生成、试运行和保存标准代码。不能提示标准兼容成功。

将代码改成：

```js
document.querySelector('#result').textContent = GM_info.script.name;
```

重新试运行并保存，导出应可用。

### 5.3 动态 GM 别名

在声明 GM_getValue 的专用测试工具中，试运行并保存：

先在需求输入框发送下面的完整要求，点击生成并确认发送内容。不要只在代码编辑框中添加 `@grant` 注释，代码编辑不会更新草稿的权限列表。

