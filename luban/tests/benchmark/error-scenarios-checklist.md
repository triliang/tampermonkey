# Phase 7 · §4.1 错误场景清单

> 对应 P7-T4。2026-10-11：断网一行已实测通过，其余场景暂不验收。

| # | 场景 | 现有文案 / 恢复动作 | 状态 |
|---|------|---------------------|------|
| 1 | AI 调用超时（60s） | 「生成已超时，请重试」；回到意图页可再点「生成脚本」 | ⏭ 暂不验收 |
| 2 | API Key 无效 / 403 / 429 | 401「API Key 无效，请检查设置。」+「打开设置」；403「API Key 已过期或权限不足。」+「打开设置」；429「调用太频繁，稍等片刻后重试。」+ 再点生成 | ⏭ 暂不验收 |
| 3 | CSP 阻止注入 | 降级链耗尽后「该站点暂不支持自动注入。」；结果页可「反馈 AI 重生成」或「返回」 | ⏭ 暂不验收 |
| 4 | 脚本运行时报错 | 「脚本运行出错」+ 摘要；「反馈 AI 重生成」把错误写回意图框 | ⏭ 暂不验收（Phase 6 第 5 项已通过） |
| 5 | 跨域 iframe / 采集失败 | 选择打到浏览器内置页时「当前页面无法采集内容（浏览器限制）。」跨域 iframe 未单独做「上下文不完整」提示 | ⏭ 暂不验收 |
| 6 | 网络完全断开 | 侧栏横幅「网络不可用」；「生成脚本」「重新生成」「反馈 AI 重生成」置灰；最近脚本与「再次运行」「运行」仍可点；恢复联网后横幅消失、按钮恢复 | ✓ 通过 |
| 7 | Service Worker 休眠后恢复 | 生成中 terminate：60 秒内回到生成并重试；超过 60 秒「生成已超时，请重试」。预览中 terminate：说明和代码还在 | ⏭ 暂不验收（Phase 6 第 7、8 项已通过） |
| 8 | 目标元素消失 | 脚本自身 try/catch 时标题仍是「脚本运行成功」，控制台有 `[鲁班]`。未捕获则「脚本运行出错」 | ⏭ 暂不验收 |
| 9 | AI 返回坏 JSON | 自动剥围栏并重试 1 次；仍失败「模型返回格式异常，已尝试重来。」，可再生成或改意图 | ⏭ 暂不验收 |
| 10 | gmGrants 越权 | 预览「安全提示」含「该脚本申请了不支持的权限：…，运行时将被打桩为空操作」；黑名单命中则「包含被禁止的操作」且「运行」不可点 | ⏭ 暂不验收 |

抽查 3 条链路里，断网已通过。错 Key、注入失败暂不验收。
